# 附录B 保密性和安全性度量

## 0. 内容总览

本附录从信息论角度研究密码体制的保密性和安全性度量。教材说明：所有概念均由香农在 1949 年里程碑式论文 [SHAN49] 中首次提出。

内容结构：

```text
保密性和安全性度量
  |
  |-- 条件概率基础（预备知识）
  |-- 完善保密性（概率论定义）
  |-- 信息与熵（香农熵理论）
  |-- 熵与保密性（信息论视角下的密码安全）
  |-- 最小熵（最坏情形安全度量）
```

## 1. 条件概率

### 1.1 定义

在事件 $B$ 发生的条件下，事件 $A$ 发生的条件概率：

$$\Pr[A \mid B] = \frac{\Pr[AB]}{\Pr[B]}, \quad \Pr[B] > 0$$

**经典示例**——掷两颗骰子，已知至少有一颗点数为偶数，求点数之和为 8 的概率。

- $A$ = {和为 8}，$B$ = {至少一颗偶数}
- 满足 $A$ 且 $B$ 的结果：(2,6)、(4,4)、(6,2) → $\Pr[AB] = 3/36 = 1/12$
- 两颗均为偶数的可能：$36 - 3 \times 3 = 27$，故 $\Pr[B] = 27/36 = 3/4$

$$\Pr[A \mid B] = \frac{1/12}{3/4} = \frac{1}{9}$$

### 1.2 独立性

若 $\Pr[AB] = \Pr[A]\Pr[B]$，则事件 $A$ 和 $B$ 独立。此时：

$$\Pr[A \mid B] = \Pr[A], \quad \Pr[B \mid A] = \Pr[B]$$

### 1.3 贝叶斯定理

$$\Pr[A \mid B] = \frac{\Pr[B \mid A] \cdot \Pr[A]}{\Pr[B]}$$

## 2. 完善保密性

### 2.1 两类保密性定义

| 类型 | 定义 |
|---|---|
| **完善保密（Perfect Secrecy）** | 无论敌手计算能力多强、花多长时间，都得不到任何信息。理想情况，实际密码体制很难实现 |
| **计算保密（Computational Secrecy）** | 除非敌手执行 $N$ 次以上运算（$N$ 极大，如几千年），否则不获得信息。实际可行 |

### 2.2 密码体制的符号化

教材引入三个随机变量：

| 变量 | 含义 |
|---|---|
| $M$ | 消息集合 $\mathcal{M}$ 中的随机变量，由其概率分布表征 |
| $K$ | 从密钥集合中均匀随机选择的加密密钥 |
| $C$ | 加密结果：$C = E(K, M)$ |

**示例**：军事基地只发送三条消息：

$$\mathcal{M} = \{\text{无报告}, \text{5 架飞机}, \text{10 架飞机}\}$$

$M$ 的一个可能分布：$M = \begin{pmatrix} m_1 & m_2 & m_3 \\ 0.6 & 0.3 & 0.1 \end{pmatrix}$（敌手知道此分布）。

### 2.3 完善保密的正式定义

引用香农（Shannon）的定义：

> "完善保密"要求：在密报被截获后，表示各条消息对应这个密报的后验概率和截获之前各条消息的先验概率完全相同。

数学表述——一个密码体制具有**完善保密性**，当且仅当对任意明文 $m$ 和任意密文 $c$：

$$\Pr[M = m \mid C = c] = \Pr[M = m]$$

即：密文不提供关于明文的任何信息。等效条件：

$$\Pr[C = c \mid M = m] = \Pr[C = c]$$

### 2.4 完善保密性的条件

教材证明：完善保密性要求密钥空间不小于明文空间——$|K| \ge |M|$。若 $|K| = |M| = |C|$，则完善保密方案要求：
- 每个密钥以等概率 $1/|K|$ 选择
- 对每个 $(m, c)$，存在唯一密钥 $k$ 使得 $E(k, m) = c$

### 2.5 一次一密（One-Time Pad）

**一次一密**是实现完善保密性的经典方案：$c_i = m_i \oplus k_i$。

必要条件：
- 密钥是真正随机的
- 密钥与消息等长
- **密钥仅使用一次**——重用破坏完善保密性

## 3. 信息与熵

### 3.1 信息量

随机变量 $X$ 取值 $x$ 的**信息量**定义为：

$$I(X = x) = \log_2\frac{1}{\Pr[X = x]} = -\log_2\Pr[X = x]$$

含义：事件发生的概率越小，发生时携带的信息量越大。单位为**比特**。

### 3.2 熵的定义

随机变量 $X$ 的**香农熵** $H(X)$ 是其信息量的数学期望，度量 $X$ 的整体不确定性：

$$H(X) = \sum_{x} \Pr[X = x] \cdot \log_2\frac{1}{\Pr[X = x]} = -\sum_{x} \Pr[X = x] \cdot \log_2\Pr[X = x]$$

若 $X$ 有 $n$ 个等可能取值，则 $H(X) = \log_2 n$ 比特——达到最大值。

### 3.3 熵函数的性质

| 性质 | 说明 |
|---|---|
| 非负性 | $H(X) \ge 0$ |
| 确定性为零 | 若 $X$ 以概率 1 取某值，$H(X) = 0$ |
| 最大化于均匀分布 | 若 $X$ 均匀分布于 $n$ 个值，$H(X) = \log_2 n$（上界） |
| 独立相加 | 若 $X$ 和 $Y$ 独立，$H(X, Y) = H(X) + H(Y)$ |

### 3.4 联合熵与条件熵

**联合熵**：

$$H(X, Y) = -\sum_{x,y} \Pr(x, y) \log_2\Pr(x, y)$$

**条件熵**——已知 $Y$ 时 $X$ 的剩余不确定性：

$$H(X \mid Y) = -\sum_{x,y} \Pr(x, y) \log_2\Pr(x \mid y)$$

**重要关系**：

$$H(X, Y) = H(Y) + H(X \mid Y) = H(X) + H(Y \mid X)$$

直观理解：联合的不确定性 = $Y$ 的不确定性 + 知道 $Y$ 后 $X$ 的剩余不确定性。

若 $X$ 和 $Y$ 独立：$H(X \mid Y) = H(X)$，$H(X, Y) = H(X) + H(Y)$。

## 4. 熵与保密性

### 4.1 密码学中的熵解读

| 概念 | 密码学含义 |
|---|---|
| $H(K)$ | 密钥的不确定性——密钥空间越大，$H(K)$ 越大 |
| $H(M)$ | 明文的不确定性——消息的先验不确定性 |
| $H(C)$ | 密文的不确定性 |
| $H(K \mid C)$ | **密钥疑义度**——已知密文后密钥的剩余不确定性 |
| $H(M \mid C)$ | **消息疑义度**——已知密文后明文的剩余不确定性 |

### 4.2 用熵表述完善保密性

**完善保密性的熵等价条件**：

$$H(M \mid C) = H(M)$$

即：已知密文不减少明文的熵——密文对明文不提供任何信息。另一个等价表述：

$$H(M) + H(K) = H(C) + H(K \mid C)$$

### 4.3 唯一解距离

**唯一解距离**（Unicity Distance）——使得密钥疑义度 $H(K \mid C^n) \approx 0$ 的最小密文量 $n$，即破译密文所需的最少密文量：

$$n_0 \approx \frac{H(K)}{R_L \cdot \log_2|P|}$$

其中：
- $H(K)$：密钥熵
- $R_L$：语言冗余度（如英语约 75%）
- $|P|$：明文字母表大小

**直觉解释**：语言冗余度越高，唯一解距离越小——密文越容易被破译。

## 5. 最小熵

### 5.1 为什么需要最小熵

教材引述 NIST 800-90C：

> 随机变量 $X$ 的最小熵（Min-Entropy）是最大的值 $m$，使得对 $X$ 的每次观察至少提供 $m$ 比特信息。最小熵常用作最坏情形下不可预测性的度量。

最小熵与香农熵的区别：
- $H(K)$：**平均**不确定性——平均需要 $2^{H(K)-1}$ 次尝试
- $H_{\infty}(K)$：**最坏情形**不确定性——最多需要 $2^{H_{\infty}(K)-1}$ 次尝试

### 5.2 数学定义

$$H_{\infty}(K) = \min_j \log_2\frac{1}{P_j} = -\log_2(\max_j P_j)$$

其中 $P_j = \Pr[K = j-1]$，即 $H_{\infty}(K)$ 完全由最可能出现的密钥值决定。

等价表述：若对所有 $j$ 有 $\Pr[K = j] \le 2^{-n}$，则 $H_{\infty}(K) \ge n$。

### 5.3 均匀分布 vs 非均匀分布

若所有密钥等可能（$P_j = 2^{-k}$），则：

$$H_{\infty}(K) = H(K) = k$$

若分布不均——最可能值的概率是平均值 2 倍（$P_{\max} = 2^{-k+1}$），则：

$$H_{\infty}(K) = k - 1 < H(K)$$

**这就是为什么随机数生成器使用加密算法消除偏差**——其目的是最大化最小熵。

### 5.4 3-比特密钥实例

教材给出一个非均匀的 3-比特密钥分布：

| $i$ | $P_i$ | $-\log_2 P_i$ |
|---|---|---|
| 0 | 1/16 | 4 |
| 1 | 1/4 | 2 |
| 2 | 1/8 | 3 |
| 3 | 1/8 | 3 |
| 4 | 1/16 | 4 |
| 5 | 1/16 | 4 |
| 6 | 1/8 | 3 |
| 7 | 3/16 | $\approx 2.415$ |

计算结果：

$$H(K) = 2.828 \text{ 比特（平均熵）}$$

$$H_{\infty}(K) = 2 \text{ 比特（最小熵，由 } i=1 \text{ 的 } P=1/4 \text{ 决定）}$$

**安全启示**：分布最可能的值（$i=1$ 概率 $1/4$）意味着敌手猜测两次就能以高概率猜中密钥——这就是最小熵衡量"最坏情形"的原因。
