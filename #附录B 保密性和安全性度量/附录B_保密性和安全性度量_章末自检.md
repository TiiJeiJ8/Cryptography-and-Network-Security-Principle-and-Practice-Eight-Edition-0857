# 附录B 保密性和安全性度量 — 章末学习目标自检

---

## 1. 能写出条件概率的定义公式和贝叶斯定理。

**条件概率**：在事件 $B$ 发生的条件下事件 $A$ 发生的概率：

$$\Pr[A \mid B] = \frac{\Pr[AB]}{\Pr[B]}, \quad \Pr[B] > 0$$

**独立性**：若 $\Pr[AB] = \Pr[A]\Pr[B]$，则 $A$、$B$ 独立，此时 $\Pr[A \mid B] = \Pr[A]$。

**贝叶斯定理**：

$$\Pr[A \mid B] = \frac{\Pr[B \mid A] \cdot \Pr[A]}{\Pr[B]}$$

它将"已知结果反推原因"的后验概率与"原因导致结果"的似然联系起来，是密码分析中由密文推断明文/密钥的数学基础。

---

## 2. 能从概率论和信息论两个角度分别表述完善保密性的条件。

**概率论角度**（香农定义）：对任意明文 $m$ 和任意密文 $c$：

$$\Pr[M = m \mid C = c] = \Pr[M = m]$$

即截获密文后，各明文的后验概率与截获前的先验概率完全相同——密文不泄露任何明文信息。等价条件：

$$\Pr[C = c \mid M = m] = \Pr[C = c]$$

**信息论角度**（熵表述）：

$$H(M \mid C) = H(M)$$

即已知密文不减少明文的熵。另一个等价关系：

$$H(M) + H(K) = H(C) + H(K \mid C)$$

**必要条件**：$|K| \geq |M|$。若 $|K| = |M| = |C|$，则每个密钥等概率 $1/|K|$ 选取，且对每对 $(m, c)$ 存在唯一密钥 $k$ 使 $E(k, m) = c$。**一次一密**（$c_i = m_i \oplus k_i$，密钥真随机、等长、仅用一次）是完善保密的经典实现。

## 3. 能写出香农熵的定义公式，并计算等可能和不等可能分布的熵。

**信息量**：随机变量 $X$ 取值 $x$ 的信息量：

$$I(X = x) = \log_2 \frac{1}{\Pr[X = x]} = -\log_2 \Pr[X = x]$$

**香农熵**（信息量的期望，度量整体不确定性）：

$$H(X) = -\sum_{x} \Pr[X = x] \log_2 \Pr[X = x]$$

**等可能分布**：$n$ 个取值各概率 $1/n$：

$$H(X) = \log_2 n \text{ 比特（最大值）}$$

**不等可能分布**：以教材军事消息为例，$P(m_1) = 0.6$，$P(m_2) = 0.3$，$P(m_3) = 0.1$：

$$H(M) = -(0.6 \log_2 0.6 + 0.3 \log_2 0.3 + 0.1 \log_2 0.1) \approx 1.296 \text{ 比特}$$

分布越不均匀，熵越小；确定事件（概率 1）熵为 0。

## 4. 能解释 $H(M)$、$H(K)$、$H(M \mid C)$ 和 $H(K \mid C)$ 各自的密码学含义。

| 符号 | 含义 |
|------|------|
| $H(M)$ | 明文的先验不确定性——敌手在看到密文前对明文的不确定程度 |
| $H(K)$ | 密钥的不确定性——密钥空间越大、分布越均匀，$H(K)$ 越大 |
| $H(M \mid C)$ | **消息疑义度**——已知密文后明文的剩余不确定性；完善保密时等于 $H(M)$ |
| $H(K \mid C)$ | **密钥疑义度**——已知密文后密钥的剩余不确定性；随密文量增加趋于 0 |

联合熵与条件熵的关系：

$$H(X, Y) = H(Y) + H(X \mid Y)$$

## 5. 能推导唯一解距离公式并解释语言冗余度如何影响破译难度。

**唯一解距离** $n_0$：使密钥疑义度 $H(K \mid C^n) \approx 0$ 所需的最少密文量，即敌手唯一确定密钥所需的密文长度：

$$n_0 \approx \frac{H(K)}{R_L \cdot \log_2 |P|}$$

其中 $H(K)$ 为密钥熵，$|P|$ 为明文字母表大小，$R_L$ 为**语言冗余度**（英语约 0.75，即 75%）。

**冗余度的影响**：$R_L$ 越大（自然语言越有结构、越可预测），分母越大，$n_0$ 越小，敌手只需较少密文即可唯一确定密钥。反之，压缩明文（去除冗余）可增大唯一解距离，提高破译难度。

## 6. 能定义最小熵，并说明它为何是"最坏情形"下的安全性度量。

**最小熵**：

$$H_{\infty}(K) = \min_j \log_2 \frac{1}{P_j} = -\log_2 \left(\max_j P_j\right)$$

它完全由**最可能出现的密钥值**决定。

与香农熵的区别：
- $H(K)$ 度量**平均**不确定性，对应平均 $2^{H(K)-1}$ 次猜测；
- $H_{\infty}(K)$ 度量**最坏情形**不确定性，对应最多 $2^{H_{\infty}(K)-1}$ 次猜测。

敌手总是从最可能的密钥开始猜，因此安全强度由最可能值决定，而非平均值。这就是 NIST 用最小熵衡量随机数不可预测性的原因。

---

## 7. 能解释为何分布不均的密钥比均匀密钥更容易被攻破。

均匀分布时所有 $2^k$ 个密钥概率均为 $2^{-k}$：

$$H_{\infty}(K) = H(K) = k$$

若分布不均，最可能值概率为 $2^{-k+1}$（平均值的 2 倍）：

$$H_{\infty}(K) = k - 1 < H(K)$$

**教材 3 比特示例**：分布 $P = [1/16, 1/4, 1/8, 1/8, 1/16, 1/16, 1/8, 3/16]$：

$$H(K) = 2.828 \text{ 比特}, \quad H_{\infty}(K) = 2 \text{ 比特（由 } P = 1/4 \text{ 决定）}$$

最可能的密钥（$i=1$，概率 $1/4$）意味着敌手平均只需猜 2 次就能以高概率命中。香农熵 2.828 给人"接近 3 比特安全"的错觉，但最小熵只有 2 比特——这正是 PRNG 使用密码学算法消除偏差、最大化最小熵的原因。
