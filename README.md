## 选择你的学习路线

### 零基础系统学习

`导学讲义` → `Note_chapter_**` → `教材原文核对` → `课后习题`

先用讲义建立直觉，再以 `Note_chapter_**` 串联学习目标和知识点；需要确认定义与推导时回到教材原文，最后用习题验证是否真正掌握。

### 考试冲刺

`Note_chapter_**` → `课后习题` → `错题回溯` → `Note_chapter_**`

从上方 `Note_chapter` 入口选择目标章节，按学习目标复习并做题；遇到薄弱点，再回到同章笔记定位知识点，必要时查阅讲义或原文。

### 视频与教材同步

按照 [配套视频观看顺序](视频观看顺序规划.md)，依次串联密码学引论、现代密码学、密码学原理和网络安全课程，使视频进度与教材章节保持一致。

## 快速开始

1. 下载或克隆本课程目录。
2. 在 [Obsidian](https://obsidian.md/) 中选择“打开本地仓库”，目录指向 `密码编码学与网络安全（第八版）`。
3. 复习第 1–8 章时，直接从上方 `Note_chapter` 表格进入对应主笔记。
4. 第一次学习建议先看导学讲义；复习阶段以 `Note_chapter_**` 为准，再配合课后习题和原文查证。
5. 其他章节暂时从 [课程总索引](_index.md) 进入现有配套文档。

仅使用普通 Markdown 阅读器也能浏览内容；Obsidian 可进一步呈现 Wiki 链接、关系跳转、LaTeX 公式与 Mermaid 图。
