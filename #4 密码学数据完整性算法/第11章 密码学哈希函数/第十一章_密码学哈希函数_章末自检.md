# 第11章 密码学哈希函数 — 章末学习目标自检

---

## 1. 能列出哈希函数在消息认证、数字签名、口令存储、入侵检测和 PRNG 中的用途。

哈希函数 $H$ 将任意长输入映射为定长输出 $h = H(M)$。主要应用：

| 应用 | 方式 |
|------|------|
| **消息认证** | 发送方计算 $H(M)$ 随消息发送，接收方重算并比对，验证完整性和来源。可配合对称密钥加密（$E(K, H(M))$）或共享秘密值 $S$（$H(M \parallel S)$）使用 |
| **数字签名** | 对哈希值而非整个消息用私钥签名：$E(PR_a, H(M))$。因为哈希值短，签名效率高；且抗碰撞性保证签名不可被挪用到另一消息 |
| **口令存储** | 操作系统只存 $H(\text{password})$，登录时比对哈希值。即使口令文件泄露，攻击者也不能由哈希值反推口令（单向性） |
| **入侵检测/病毒检测** | 为每个文件计算并安全保存 $H(F)$，定期重算比对。文件被篡改则哈希值改变 |
| **PRNG/PRF** | 哈希函数的伪随机输出可用于构造伪随机数生成器或伪随机函数 |

消息认证的四种典型方案：
- (a) $E(K, M \parallel H(M))$：加密整个消息+哈希，提供保密性和认证；
- (b) $M \parallel E(K, H(M))$：只加密哈希，明文传输，降低加密开销；
- (c) $M \parallel H(M \parallel S)$：用共享秘密 $S$ 不加密，适合不支持加密的场景；
- (d) $E(K, M \parallel H(M \parallel S))$：同时加密和使用秘密值。

## 2. 能说明在使用哈希码进行消息认证时，若哈希值不被保护（如中间人攻击），敌手可如何绕过检测。

如果哈希值不以任何方式保护（既不加密也不使用秘密值），攻击者可以：

1. **截获消息 $M$ 和哈希值 $H(M)$**；
2. **篡改消息为 $M'$**（任意修改内容）；
3. **重新计算 $H(M')$** 并替换原哈希值；
4. 将 $M' \parallel H(M')$ 发给接收方。

接收方重算哈希值得到 $H(M')$，与附带的哈希值一致，因此**无法检测篡改**。这就是方案 $M \parallel H(M)$（无密钥、无秘密）不提供任何安全性的原因——哈希函数是公开的，任何人都能计算。

保护方式：① 用对称密钥加密哈希值（$E(K, H(M))$），攻击者没有密钥无法伪造合法哈希；② 使用发送方和接收方共享的秘密值 $S$（$H(M \parallel S)$），攻击者不知道 $S$ 就无法为篡改后的消息计算正确哈希；③ 用私钥对哈希值签名（数字签名），攻击者没有私钥无法伪造签名。

## 3. 能区分抗原像（单向性）、抗第二原像（弱碰撞）和抗强碰撞三种安全要求及其针对的攻击场景。

| 安全要求 | 攻击场景 | 形式化描述 |
|----------|----------|-----------|
| **抗原像攻击（单向性）** | 给定哈希值 $h$，找任意输入 $y$ 使 $H(y) = h$ | 对任意 $h$，求 $y$ 不可行 |
| **抗第二原像攻击（抗弱碰撞）** | 给定输入 $x$，找另一个 $y \neq x$ 使 $H(y) = H(x)$ | 对任意 $x$，求 $y \neq x$ 不可行 |
| **抗碰撞攻击（抗强碰撞）** | 自由找任意一对 $x \neq y$ 使 $H(x) = H(y)$ | 找 $(x, y)$ 不可行 |

**各要求保护的场景**：
- **抗原像**：保护口令存储——攻击者拿到哈希值不能反推口令。
- **抗第二原像**：保护消息认证和入侵检测——攻击者不能为给定消息找一个哈希相同的伪造消息。
- **抗强碰撞**：保护数字签名——攻击者不能准备两版哈希相同但含义不同的消息（如一份合同和一份欠条），诱骗对方签一版后声称签的是另一版。

**蕴含关系**：抗强碰撞 $\Rightarrow$ 抗第二原像 $\Rightarrow$ 抗原像（能找任意碰撞的攻击者，给定 $x$ 也能找碰撞；能找第二原像的攻击者，给定 $h$ 取一个原像 $x$ 后也能找第二原像）。但反之不成立。

## 4. 能解释生日攻击的原理，并说明 $n$ 位哈希码的抗碰撞强度仅约为 $n/2$ 位。

**生日悖论**：在 $N$ 个可能值中随机选取 $k$ 个，存在重复的概率约为 $1/2$ 时，$k \approx 1.18\sqrt{N}$。例如 365 天中只需约 23 人就有 50% 概率两人生日相同。

**生日攻击哈希函数**：攻击者准备两组消息（如合法合同的 $2^{n/2}$ 个变体和欺诈合同的 $2^{n/2}$ 个变体），分别计算哈希值。两组各 $2^{n/2}$ 个哈希值中存在碰撞的概率约为 $1/2$，即找到 $x \neq y$ 使 $H(x) = H(y)$ 的工作量约为 $2^{n/2}$，而非 $2^n$。

对比：
- 抗原像/第二原像攻击需约 $2^n$ 次尝试；
- 抗碰撞攻击只需约 $2^{n/2}$ 次尝试。

因此 $n$ 位哈希值的抗碰撞安全强度只有 $n/2$ 位。这就是 SHA-1（160 位）抗碰撞强度仅 80 位、已被实际碰撞攻破（2017 年），而现代标准要求 SHA-256（抗碰撞 128 位）或 SHA-512（抗碰撞 256 位）的原因。

## 5. 能画出迭代哈希函数的基本结构 $CV_i = f(CV_{i-1}, Y_{i-1})$，并说明压缩函数抗碰撞是整体抗碰撞的充分条件。

大多数密码学哈希函数采用 **Merkle-Damgård 迭代结构**：

$$CV_0 = IV \text{（初始值）}$$
$$CV_i = f(CV_{i-1}, Y_{i-1}), \quad i = 1, \ldots, L$$
$$H(M) = CV_L$$

其中：
- $Y_0, Y_1, \ldots, Y_{L-1}$ 是消息经填充后分成的 $L$ 个固定长度分组；
- $CV_i$ 是第 $i$ 步的链接变量（chaining variable）；
- $f$ 是**压缩函数**，输入前一轮链接变量和当前消息分组，输出新的链接变量；
- $IV$ 是固定初始值。

消息先填充至分组长度的整数倍（通常附加 1、若干 0 和原始长度字段），然后逐块压缩。

**充分性证明思路**：如果整个哈希函数存在碰撞 $H(x) = H(y)$ 且 $x \neq y$，设它们在迭代中最后一个不同的分组为第 $i$ 块，则压缩函数的输入 $(CV_{i-1}, Y_{i-1})$ 不同但输出 $CV_i$ 相同（或最终输出相同），即压缩函数 $f$ 存在碰撞。因此：若 $f$ 抗碰撞，则整个哈希函数抗碰撞。

## 6. 能说明用分组密码构建哈希函数时，Davies-Meyer 方案与单纯加密方案的区别。

**Rabin 方案（单纯加密）**：

$$CV_i = E(Y_{i-1}, CV_{i-1})$$

将消息分组 $Y_{i-1}$ 作为密钥，前一链接变量 $CV_{i-1}$ 作为明文加密。该方案较简单，但存在安全弱点。

**Davies-Meyer 方案（带前馈）**：

$$CV_i = E(Y_{i-1}, CV_{i-1}) \oplus CV_{i-1}$$

在加密结果上再 XOR 前一链接变量（前馈）。这一额外反馈破坏了分组密码的一些代数结构，使攻击者更难构造碰撞，其抗碰撞性可归约到底层分组密码对差分密码分析的抵抗能力。

区别本质：Rabin 方案中压缩函数的输出就是密文，攻击者可能利用分组密码的弱点（如密钥已知时的结构）；Davies-Meyer 的前馈使输出 $E(K, P) \oplus P$ 成为一个"单向"构造——即使知道密钥（消息分组是公开的），从输出反推输入也需要解 $E(K, P) \oplus P = CV_i$，这不是简单的解密。Davies-Meyer 是许多实际哈希构造的基础。

## 7. 能写出 SHA-512 的填充规则（长度模 1024 余 896 + 128 位长度），以及 80 轮中 $T_1$、$T_2$ 和寄存器更新关系。

**填充规则**：
1. 附加填充位：先填一个 1，再填若干 0，使消息长度 $\equiv 896 \pmod{1024}$。无论原长是否满足都填充，填充位数 $1 \sim 1024$。
2. 附加长度：末尾追加 128 位无符号整数，表示填充前原始消息的位长度。最终消息总长为 1024 的整数倍。

**缓冲区初始化**：8 个 64 位寄存器 $(a,b,c,d,e,f,g,h)$，初始值取前 8 个素数平方根小数部分的前 64 位。

**每个 1024 位分组处理 80 轮**，每轮更新：

$$T_1 = h + \text{Ch}(e,f,g) + \Sigma_1^{512}(e) + W_t + K_t$$
$$T_2 = \Sigma_0^{512}(a) + \text{Maj}(a,b,c)$$

$$h = g,\ g = f,\ f = e,\ e = d + T_1$$
$$d = c,\ c = b,\ b = a,\ a = T_1 + T_2$$

其中：
- $\text{Ch}(e,f,g) = (e \land f) \oplus (\neg e \land g)$（选择函数，按 $e$ 选 $f$ 或 $g$）；
- $\text{Maj}(a,b,c) = (a \land b) \oplus (a \land c) \oplus (b \land c)$（多数函数）；
- $\Sigma_0^{512}(a) = \text{ROTR}^{28}(a) \oplus \text{ROTR}^{34}(a) \oplus \text{ROTR}^{39}(a)$；
- $\Sigma_1^{512}(e) = \text{ROTR}^{14}(e) \oplus \text{ROTR}^{18}(e) \oplus \text{ROTR}^{41}(e)$；
- $W_t$ 为消息字，$K_t$ 为轮常数（前 80 个素数立方根小数部分前 64 位）。

**消息扩展**：$W_0 \sim W_{15}$ 直接取自消息分组；$t \geq 16$ 时：

$$W_t = \sigma_1^{512}(W_{t-2}) + W_{t-7} + \sigma_0^{512}(W_{t-15}) + W_{t-16} \pmod{2^{64}}$$

每个分组处理完后，8 个寄存器输出与输入 $H_{i-1}$ 逐字模 $2^{64}$ 相加：$H_i = \text{SUM}_{64}(H_{i-1}, \text{abcdefgh}_i)$。最终 $H_N$ 为 512 位摘要。

## 8. 能说明海绵结构两个阶段的工作原理，以及位速率 $r$ 和容量 $c$ 对速度和安全的影响。

SHA-3（Keccak）采用**海绵结构**，状态长度 $b = r + c$：

- **$r$（位速率）**：每轮吸收/输出的位数；
- **$c$（容量）**：不直接接触输入输出的部分，决定安全强度；
- Keccak 默认 $b = 1600$，$c = 1024$，$r = 576$。

**吸收阶段**：
1. 状态 $s$ 初始全 0；
2. 消息经 pad10*1 填充后分为 $r$ 位分组；
3. 每个分组填充 0 至 $b$ 位，与当前状态 $s$ XOR；
4. 经置换函数 $f$（Keccak-f[1600]，24 轮）更新 $s$；
5. 重复直到所有消息分组处理完毕。

**挤压阶段**：
1. 若所需输出 $\ell \leq r$，直接输出 $s$ 的前 $r$ 位；
2. 否则输出前 $r$ 位后，再执行 $f$ 更新 $s$，继续输出前 $r$ 位，拼接直到满足 $\ell$ 位。

**$r$ 和 $c$ 的权衡**：$r$ 越大，每轮处理的消息越多，速度越快，但 $c = b - r$ 越小，安全强度越低（安全强度约为 $c/2$ 位）。反之 $c$ 越大越安全但速度越慢。海绵结构统一了哈希、MAC、PRNG、可变长度输出等功能。

## 9. 能列出 Keccak-f 五个阶跃函数（$\theta$、$\rho$、$\pi$、$\chi$、$\iota$）各自的作用。

Keccak-f[1600] 的状态是 $5 \times 5 \times 64$ 的三维位数组 $a[x][y][z]$（25 个 64 位"通道"），共 24 轮，每轮依次执行五个阶跃：

| 阶跃 | 名称 | 作用 | 线性/非线性 |
|------|------|------|------------|
| $\theta$（theta） | 扩散 | 计算每列的奇偶性，将每位与相邻两列的奇偶性 XOR，提供列间扩散 | 线性 |
| $\rho$（rho） | 通道内旋转 | 对 25 个通道各自循环左移不同的常数偏移量，提供通道内位间扩散 | 线性 |
| $\pi$（pi） | 通道间置换 | 在 $5 \times 5$ 通道矩阵中重新排列各通道位置，提供通道间扩散 | 线性 |
| $\chi$（chi） | 非线性混合 | $a[x] \leftarrow a[x] \oplus (\neg a[x+1] \land a[x+2])$，沿 $x$ 方向做逐位非线性组合，是唯一的非线性步骤 | **非线性** |
| $\iota$（iota） | 轮常数注入 | 将每轮不同的 64 位常数 XOR 到通道 $a[0][0]$，打破轮间对称性，防止对称性攻击 | 线性 |

设计特点：$\theta, \rho, \pi$ 提供快速扩散（线性层），$\chi$ 提供混淆（唯一非线性层，类似 S 盒），$\iota$ 确保每轮运算不同防止 slide 攻击。24 轮的迭代使雪崩效应充分扩散。
