# 第13章 数字签名 — 章末学习目标自检

---

## 1. 能否说明数字签名的一般生成与验证过程，以及它为何能认证消息来源和完整性？

**生成过程**（Bob 向 Alice 发送 $M$）：

1. Bob 计算消息哈希 $h = H(M)$；
2. Bob 将 $h$ 和自己的**私钥**输入签名生成算法，得到签名 $S$；
3. Bob 发送 $M \parallel S$。

**验证过程**：

4. Alice 对收到的消息重新计算 $H(M)$；
5. Alice 将消息哈希、签名 $S$ 和 Bob 的**公钥**输入验证算法；
6. 验证算法返回有效或无效。

**为何能认证来源和完整性**：
- **来源认证**：只有 Bob 掌握其私钥，其他任何人不能生成能通过 Bob 公钥验证的签名；
- **完整性**：若消息被修改，重新计算的哈希值改变，原签名无法通过验证。

数字签名还须满足：验证签名者及签名时间、认证消息内容、争执时可由第三方仲裁。这是 MAC 做不到的——MAC 双方共享密钥，接收方可以伪造消息，发送方也可以否认，因此**MAC 不提供不可否认性**，而数字签名可以。

攻击类型按能力递增：唯密钥攻击、已知消息攻击、一般选择消息攻击、定向选择消息攻击、适应性选择消息攻击。伪造结果按危害：完全破译（恢复私钥）、通用伪造、选择伪造、存在性伪造。

## 2. 能否写出 ElGamal 的密钥生成、$(S_1,S_2)$ 签名公式和 $V_1=V_2$ 验证公式？

**全局参数**：素数 $q$，本原根 $\alpha$。

**密钥生成**：

$$X_A \in (1, q-1) \text{（私钥，随机选取）}$$

$$Y_A = \alpha^{X_A} \bmod q \text{（公钥）}$$

**签名生成**：计算 $m = H(M)$，选择随机整数 $K$，满足 $1 \le K \le q-1$ 且 $\gcd(K, q-1) = 1$：

$$S_1 = \alpha^K \bmod q$$

$$S_2 = K^{-1}(m - X_A S_1) \bmod (q-1)$$

签名为 $(S_1, S_2)$。

**签名验证**：

$$V_1 = \alpha^m \bmod q$$

$$V_2 = Y_A^{S_1} S_1^{S_2} \bmod q$$

当且仅当 $V_1 = V_2$ 时接受。

**正确性证明**：

$$V_2 = \alpha^{X_A S_1} \cdot \alpha^{K S_2} = \alpha^{X_A S_1 + K S_2} \pmod{q}$$

由签名公式 $K S_2 \equiv m - X_A S_1 \pmod{q-1}$，得 $X_A S_1 + K S_2 \equiv m \pmod{q-1}$。利用 $\alpha^i \equiv \alpha^j \pmod{q} \iff i \equiv j \pmod{q-1}$，有 $V_2 = \alpha^m = V_1$。

**教材示例**：$q=19$，$\alpha=10$，$X_A=16$，$Y_A=4$。$m=14$，$K=5$：$S_1=10^5 \bmod 19 = 3$，$K^{-1} \bmod 18 = 11$，$S_2 = 11(14-16\times3) \bmod 18 = 4$。验证：$V_1=10^{14}\bmod 19=16$，$V_2=4^3 \cdot 3^4 \bmod 19=16$，签名 $(3,4)$ 有效。

## 3. 能否说明 Schnorr 方案中 $x$、$e$、$y$ 的作用，并证明验证端能够重构 $x$？

**全局参数**：素数 $p, q$（$q \mid p-1$），阶为 $q$ 的元素 $a$（$a^q \equiv 1 \pmod p$）。私钥 $s$，公钥 $v = a^{-s} \bmod p$。

签名生成：

1. 选择随机 $r$（$0 < r < q$），**预计算**：
   $$x = a^r \bmod p$$
   $x$ 是承诺值，不依赖消息，可在空闲时预先计算；
2. 将 $x$ 与消息绑定，计算挑战值：
   $$e = H(M \parallel x)$$
   $e$ 是哈希挑战，把消息和承诺绑定在一起；
3. 计算响应：
   $$y = (r + se) \bmod q$$
   $y$ 是对挑战的响应，证明知道私钥 $s$ 而不泄露它。

签名为 $(e, y)$。

**验证端重构 $x$**：

$$x' = a^y v^e \bmod p$$

检验 $e \stackrel{?}{=} H(M \parallel x')$。

**正确性**：

$$x' = a^y v^e = a^{r+se} \cdot a^{-se} = a^r = x \pmod{p}$$

因此 $H(M \parallel x') = H(M \parallel x) = e$。Schnorr 方案的主要优势是 $x = a^r$ 不依赖消息，主要指数运算可预处理，签名时计算量少。

## 4. 能否写出 DSA 的全局参数、密钥、签名 $(r,s)$ 和验证值 $v$ 的完整计算过程？

**全局参数**（一组用户共享）：

- $q$：$N$ 位素数；
- $p$：素数，$q \mid (p-1)$；
- $g = h^{(p-1)/q} \bmod p$，$g > 1$。

**用户密钥**：私钥 $x$（$0 < x < q$），公钥 $y = g^x \bmod p$。

**签名生成**：选择唯一随机数 $k$（$0 < k < q$）：

$$r = (g^k \bmod p) \bmod q$$

$$s = \left[k^{-1}\bigl(H(M) + xr\bigr)\right] \bmod q$$

签名为 $(r, s)$。$g^k \bmod p$ 和 $k^{-1} \bmod q$ 不依赖消息，可预先计算。

**签名验证**：收到 $(M', r', s')$：

$$w = (s')^{-1} \bmod q$$

$$u_1 = H(M')w \bmod q, \qquad u_2 = r'w \bmod q$$

$$v = \left[(g^{u_1} y^{u_2}) \bmod p\right] \bmod q$$

当且仅当 $v = r'$ 时签名有效。

**正确性**：代入 $y = g^x$，$u_1 = H(M)w$，$u_2 = rw$，$w = s^{-1}$：

$$u_1 + xu_2 = w(H(M) + xr) = s^{-1} \cdot s \cdot k \equiv k \pmod{q}$$

因此 $g^{u_1} y^{u_2} = g^{u_1 + xu_2} = g^k \pmod p$，故 $v = (g^k \bmod p) \bmod q = r$。DSA 只提供数字签名功能，不能用于加密或密钥交换。

## 5. 能否从参数结构、随机量、签名形式和验证方法四方面比较 ElGamal、Schnorr 与 DSA？

三种方案都基于有限域离散对数困难性，都先哈希消息，每次签名引入随机数。

| 比较项 | ElGamal | Schnorr | DSA |
| --- | --- | --- | --- |
| **参数结构** | 素数 $q$ 与本原根 $\alpha$ | 素数 $p, q$（$q \mid p-1$），阶为 $q$ 的 $a$ | 素数 $p, q$（$q \mid p-1$），$g = h^{(p-1)/q} \bmod p$ |
| **私钥/公钥** | $X_A$；$Y_A = \alpha^{X_A} \bmod q$ | $s$；$v = a^{-s} \bmod p$ | $x$；$y = g^x \bmod p$ |
| **每次随机量** | $K$，须 $\gcd(K, q-1) = 1$ | $r$ | 唯一的 $k$ |
| **签名形式** | $(S_1, S_2)$，均为模 $q$/$q-1$ 整数 | $(e, y)$，$e$ 为哈希值 | $(r, s)$，均为模 $q$ 整数 |
| **消息进入方式** | $m = H(M)$ 出现在 $S_2$ | $e = H(M \parallel a^r)$，承诺纳入哈希 | $H(M)$ 出现在 $s$ 中 |
| **验证方法** | 比较 $\alpha^m$ 与 $Y_A^{S_1} S_1^{S_2}$ | 重构 $x' = a^y v^e$，重算哈希比较 | 由公钥和签名恢复 $v$，比较 $v$ 与 $r$ |
| **可预处理部分** | $\alpha^K$、$K^{-1}$ | $a^r$（预处理优势最突出） | $g^k$、$k^{-1}$ |

关键区别：Schnorr 把预计算承诺 $x$ 纳入哈希挑战；DSA 的 $r$ 只依赖全局参数和 $k$，再由 $s$ 把消息哈希与私钥联系，验证最终恢复并比较 $r$，而非直接比较两个哈希值。

## 6. 能否写出 ECDSA 的签名与验证公式，并说明 $u_1G+u_2Q=kG$ 为什么成立？

**全局参数**：素数域 $Z_q$ 上曲线 $y^2 = x^3 + ax + b$，基点 $G = (x_g, y_g)$，$G$ 的阶为 $n$。私钥 $d \in [1, n-1]$，公钥 $Q = dG$。

**签名生成**：选择随机 $k \in [1, n-1]$：

$$P = (x, y) = kG, \qquad r = x \bmod n$$

$$s = k^{-1}(e + dr) \bmod n, \qquad e = H(m)$$

若 $r = 0$ 或 $s = 0$ 则重新选 $k$。签名为 $(r, s)$。

**签名验证**：

$$w = s^{-1} \bmod n$$

$$u_1 = ew \bmod n, \qquad u_2 = rw \bmod n$$

$$X = (x_1, y_1) = u_1 G + u_2 Q$$

$$v = x_1 \bmod n$$

当且仅当 $v = r$ 时接受。

**$u_1 G + u_2 Q = kG$ 的证明**：

由签名公式 $s = k^{-1}(e + dr)$，得 $k = s^{-1}(e + dr) = s^{-1}e + s^{-1}dr \pmod n$。代入：

$$u_1 G + u_2 Q = ew \cdot G + rw \cdot dG = (ew + rwd)G = w(e + dr)G = kG$$

因此验证端计算的点 $X$ 等于签名端的 $P = kG$，其横坐标模 $n$ 即为 $r$，故 $v = r$。ECDSA 基于椭圆曲线离散对数问题，在同等安全强度下密钥比 DSA 短得多。

## 7. 能否说明 RSA-PSS 中盐、MGF1、`maskedDB`、$H$ 和 `0xBC` 的作用，并概括编码与验证流程？

RSA-PSS 是基于 RSA 的**概率签名方案**，同一私钥对同一消息两次签名产生不同结果。

各组件作用：

| 组件 | 作用 |
| --- | --- |
| **盐（salt）** | 每次签名随机生成的字节串（通常长 $\operatorname{hLen}$ 字节），使签名随机化，作用类似 DSA/ECDSA 中的随机数 $k$ |
| **MGF1** | 掩蔽生成函数，基于哈希和递增计数器生成任意长度伪随机串：$\operatorname{Hash}(X \parallel 0) \parallel \operatorname{Hash}(X \parallel 1) \parallel \cdots$，截断到所需长度 |
| **$H$** | 对 $M' = \operatorname{padding}_1 \parallel \operatorname{mHash} \parallel \operatorname{salt}$ 的哈希值，是验证的核心比对值 |
| **`maskedDB`** | $DB = \operatorname{padding}_2 \parallel \operatorname{salt}$ 与 $\operatorname{dbMask} = \operatorname{MGF}(H, \cdots)$ 异或的结果，掩蔽了盐和填充 |
| **`0xBC`** | 编码消息 $EM$ 末尾的固定分隔字节，验证时检查其存在以确认格式正确 |

**编码流程**：

1. $\operatorname{mHash} = \operatorname{Hash}(M)$；
2. 生成随机 salt，$M' = \operatorname{padding}_1 \parallel \operatorname{mHash} \parallel \operatorname{salt}$；
3. $H = \operatorname{Hash}(M')$；
4. $DB = \operatorname{padding}_2 \parallel \operatorname{salt}$；
5. $\operatorname{dbMask} = \operatorname{MGF}(H, \operatorname{emLen} - \operatorname{hLen} - 1)$；
6. $\operatorname{maskedDB} = DB \oplus \operatorname{dbMask}$；
7. $EM = \operatorname{maskedDB} \parallel H \parallel \texttt{BC}$。

**签名**：$s = m^d \bmod n$（将 $EM$ 视为整数 $m$）。

**验证流程**：用公钥恢复 $m = s^e \bmod n$，还原 $EM$；检查末字节为 `0xBC`；分离 `maskedDB` 和 $H$；用 MGF 恢复 $DB = \operatorname{maskedDB} \oplus \operatorname{dbMask}$；检查 padding 格式并取出 salt；重新计算 $H' = \operatorname{Hash}(\operatorname{padding}_1 \parallel \operatorname{Hash}(M) \parallel \operatorname{salt})$；所有格式检查通过且 $H = H'$ 时签名有效。验证者无需事先知道盐值——盐从 $EM$ 中恢复。
