# 第9章 公钥密码学与RSA — 章末学习目标自检

---

## 1. 能说明公钥密码体制六要素，并解释保密性和认证两种应用模式中各使用哪一方的密钥。

公钥密码体制由六个要素组成：

| 要素 | 说明 |
|------|------|
| 明文 | 可读的消息或数据，算法的输入 |
| 加密算法 | 对明文进行各种变换 |
| 公钥和私钥 | 一对密钥，一个加密则另一个解密；从一个推出另一个在计算上不可行 |
| 密文 | 输出的置乱消息，取决于明文和密钥 |
| 解密算法 | 接收密文和相应密钥，恢复原始明文 |

**保密性模式**：发送方使用**接收方的公钥** $PU_b$ 加密，只有接收方持有对应的私钥 $PR_b$ 能解密：

$$C = E(PU_b, M), \quad M = D(PR_b, C)$$

**认证（数字签名）模式**：发送方使用**自己的私钥** $PR_a$ "签名"，任何人可用发送方的公钥 $PU_a$ 验证：

$$C = E(PR_a, M), \quad M = D(PU_a, C)$$

两者可结合：先用发送方私钥签名，再用接收方公钥加密，同时提供认证和保密。

教材还指出三个常见误解：①公钥密码不比传统密码"原则上更安全"（安全性取决于密钥长度和计算量）；②公钥密码不会取代传统密码（计算量大，仅限密钥管理和签名）；③公钥密码的密钥分发并不简单（仍需协议和中心代理）。

## 2. 能区分加密/解密、数字签名、密钥交换三类应用，并举例说明各支持哪些算法。

| 应用 | 机制 | 支持的算法 |
|------|------|-----------|
| **加密/解密** | 发送方用接收方公钥加密，接收方用自己私钥解密 | RSA、椭圆曲线（ECC） |
| **数字签名** | 发送方用自己私钥对消息（实际是哈希值）签名，接收方用发送方公钥验证 | RSA、椭圆曲线（ECDSA）、DSS |
| **密钥交换** | 双方交换信息以建立共享会话密钥 | RSA、椭圆曲线（ECDH）、Diffie-Hellman |

- **RSA** 三种应用都支持。
- **Diffie-Hellman** 仅支持密钥交换，不支持加密/解密和签名。
- **DSS**（数字签名标准）仅支持数字签名，不支持加密或密钥交换。
- **椭圆曲线密码** 三种应用都支持，且密钥更短。

## 3. 能完整陈述公钥密码六项要求，从而推出一对密钥的本质就是一个单向陷门函数。

Diffie 和 Hellman 提出公钥密码体制必须满足的六项条件：

1. 产生密钥对 $(PU_b, PR_b)$ 在计算上容易。
2. 已知公钥 $PU_b$ 和消息 $M$，计算 $C = E(PU_b, M)$ 容易。
3. 已知私钥 $PR_b$，解密 $M = D(PR_b, C)$ 容易。
4. 已知 $PU_b$ 时，确定 $PR_b$ 在计算上不可行。
5. 已知 $PU_b$ 和 $C$ 时，恢复 $M$ 在计算上不可行。
6. （可选）两个密钥顺序可交换：$D(PU, E(PR, M)) = D(PR, E(PU, M)) = M$。

**单向陷门函数** $f_k$ 满足：
- 已知 $k$ 和 $X$，$Y = f_k(X)$ 容易计算（对应条件 2，正向加密）；
- 已知 $k$ 和 $Y$，$X = f_k^{-1}(Y)$ 容易计算（对应条件 3，带私钥解密）；
- 已知 $Y$ 但 $k$ 未知，求 $X$ 不可行（对应条件 4、5，无私钥则无法解密或推私钥）。

公钥就是公开的函数描述，私钥就是陷门信息 $k$。条件 1 保证密钥生成可行，条件 6 保证同一对密钥可同时用于加密和签名。因此，公钥密码体制的核心就是寻找合适的单向陷门函数。

## 4. 能写出 RSA 的公钥构造：$n = pq$，$\phi(n) = (p-1)(q-1)$，$ed \equiv 1 \pmod{\phi(n)}$，并解释为何正确。

**密钥生成**：

| 元素 | 计算 | 状态 |
|------|------|------|
| $p, q$ | 两个大素数 | 保密 |
| $n = pq$ | 模数 | 公开 |
| $\phi(n) = (p-1)(q-1)$ | 欧拉函数 | 保密 |
| $e$ | $\gcd(\phi(n), e) = 1$，$1 < e < \phi(n)$ | 公开 |
| $d$ | $ed \equiv 1 \pmod{\phi(n)}$，即 $d \equiv e^{-1} \pmod{\phi(n)}$ | 保密 |

公钥 $\{e, n\}$，私钥 $\{d, n\}$。

**加解密**：$C = M^e \bmod n$，$M = C^d \bmod n$。

**正确性证明**：由 $ed \equiv 1 \pmod{\phi(n)}$，有 $ed = 1 + k\phi(n)$。对 $\gcd(M, n) = 1$ 的情况，由欧拉定理 $M^{\phi(n)} \equiv 1 \pmod{n}$：

$$M^{ed} = M^{1+k\phi(n)} = M \cdot (M^{\phi(n)})^k \equiv M \cdot 1^k = M \pmod{n}$$

对 $\gcd(M, n) \neq 1$ 的情况（即 $M$ 是 $p$ 或 $q$ 的倍数），利用中国剩余定理分别在模 $p$ 和模 $q$ 下验证，结论同样成立。因此 $C^d \bmod n = M^{ed} \bmod n = M$。

**教材示例**：$p=17, q=11$，$n=187$，$\phi(n)=160$，选 $e=7$，$d=23$（$7 \times 23 = 161 \equiv 1 \pmod{160}$）。加密 $M=88$：$C = 88^7 \bmod 187 = 11$；解密：$11^{23} \bmod 187 = 88$。

## 5. 能说明快速模幂、用 CRT 加速解密（约 4 倍）、概率素性测试和扩展欧几里得算法在 RSA 中的角色。

| 算法 | 在 RSA 中的角色 |
|------|----------------|
| **快速模幂（平方-乘法）** | 计算 $M^e \bmod n$ 和 $C^d \bmod n$。将指数按二进制逐位扫描，每步平方，遇 1 则乘底数。$k$ 位指数只需 $O(k)$ 次模乘，使大指数运算可行 |
| **CRT 加速解密** | 利用 $n = pq$ 将模 $n$ 的模幂拆为模 $p$ 和模 $q$ 两个小规模运算，再用中国剩余定理合并。指数可降为 $d \bmod (p-1)$ 和 $d \bmod (q-1)$，运算数长度减半，速度约提升 4 倍 |
| **概率素性测试** | 密钥生成时需要大素数 $p, q$。随机选奇数后用 Miller-Rabin 等测试检验素性，未通过则重选。由素数定理，$N$ 附近约每 $\ln N$ 个数有一个素数，只需测试约 $\ln(N)/2$ 个奇数 |
| **扩展欧几里得算法** | 已知 $e$ 和 $\phi(n)$，计算 $d \equiv e^{-1} \pmod{\phi(n)}$。扩展欧几里得算法在求 $\gcd(e, \phi(n))$ 的同时给出逆元 |

CRT 加速的具体公式：

$$V_p = C^{d \bmod (p-1)} \bmod p, \quad V_q = C^{d \bmod (q-1)} \bmod q$$
$$M = (V_p X_p + V_q X_q) \bmod n$$

其中 $X_p = q(q^{-1} \bmod p)$，$X_q = p(p^{-1} \bmod q)$ 为预计算系数。

## 6. 能解释计时攻击如何利用幂运算中的条件分支，以及不变时间、随机延时和隐蔽三种防御策略。

**计时攻击原理**：快速模幂算法逐位处理指数，每步都执行平方，但当指数位为 1 时额外执行一次乘法。这导致不同指数位对应的运算时间不同。攻击者通过精确测量多次解密操作的时间，统计分析时间差异，逐位推断私钥 $d$ 的二进制位——类似通过听转动拨号盘的时间猜测保险柜密码。

**三种防御**：

| 防御方法 | 原理 | 代价 |
|----------|------|------|
| **不变幂运算时间** | 保证所有模幂运算返回前执行固定的操作序列（无论位为 0 或 1 都执行乘法，只是不使用结果），消除时间差异 | 降低性能 |
| **随机延时** | 在模幂中加入随机延时，模糊时间信号 | 若噪声不足，攻击者可通过更多次测量平均掉随机延时 |
| **隐蔽（Blinding）** | 幂运算前将密文乘以随机数 $r^e \bmod n$，使攻击者不知道正在处理的实际密文，无法关联时间与特定密文 | 性能降低 2%~10%，最常用 |

隐蔽步骤：①生成随机 $r$；②$C' = C \cdot r^e \bmod n$；③$M' = (C')^d \bmod n$；④$M = M' \cdot r^{-1} \bmod n$。

## 7. 能说明 RSA 安全性建立在因子分解困难性的基础之上，并清楚 2010 年后对密钥长度的升级建议和 $p, q$ 的选择限制。

针对 RSA 的数学攻击有三条途径：①分解 $n = pq$；②直接确定 $\phi(n)$；③直接确定 $d$。三者在计算上等价——知道 $\phi(n)$ 即可分解 $n$，知道 $d$ 也可分解 $n$。因此 RSA 的安全性归结为大整数分解的困难性。

**因子分解进展**：

| 事件 | 年份 | 规模 |
|------|------|------|
| RSA-129 被预测需 $4 \times 10^{16}$ 年 | 1977 | 129 位十进制 |
| RSA-129 实际被攻破 | 1994 | 129 位十进制，8 个月 |
| RSA-768 被分解 | 2010 | 768 位二进制 |

**密钥长度建议**：NIST SP 800-131A（2015）建议 2048 位或更长；欧盟 ENISA 建议 3072 位或更长；加拿大 CSE 建议至少 2048 位，2030 年前升至 3072 位。

**$p, q$ 的选择限制**：
1. $p$ 和 $q$ 长度仅相差几位（防止 Fermat 分解等）；
2. $p-1$ 和 $q-1$ 都应包含大素因子（防止 $p-1$ 分解法）；
3. $\gcd(p-1, q-1)$ 应较小；
4. 私钥 $d$ 应足够大：若 $d < n^{1/4}$，$d$ 可被 Wiener 攻击等方法恢复。

## 8. 能解释 RSA 的乘法性质如何导致选择密文攻击，以及 OAEP 如何通过哈希和随机种子打破该性质。

**RSA 的乘法性质**：

$$E(PU, M_1) \times E(PU, M_2) = M_1^e \cdot M_2^e \bmod n = (M_1 \times M_2)^e \bmod n = E(PU, M_1 \times M_2)$$

即两个密文相乘等于对应明文相乘后再加密。

**简单 CCA 示例**：攻击者想解密 $C = M^e \bmod n$，但无法直接要求解密 $C$。攻击者计算 $X = C \times 2^e \bmod n = (2M)^e \bmod n$，提交 $X$ 给解密预言机（如自动解密服务），得到 $Y = X^d \bmod n = 2M \bmod n$，则 $M = Y/2 \bmod n$。

**OAEP（最优非对称加密填充）** 的防御：加密前对明文 $M$ 进行随机化填充：
1. 用可选参数 $P$ 经哈希后填充，形成数据块 DB；
2. 随机选择种子 seed，经掩码生成函数 MGF 产生掩码，与 DB XOR 得到 maskedDB；
3. maskedDB 再经 MGF 产生掩码与 seed XOR 得到 maskedSeed；
4. 编码消息 $EM = \text{maskedSeed} \parallel \text{maskedDB}$，最后对 EM 做 RSA 加密。

由于每次加密使用随机种子，同一明文每次产生不同密文（概率加密），且密文不再保持乘法同态性质——$E(M_1) \times E(M_2) \neq E(M_1 \times M_2)$，从而使 CCA 不可行。OAEP 将确定性的教科书 RSA 提升为具有可证明安全性的加密体制。
