在密码学（特别是 [[../Note_chapter_9|Note_chapter_9]] 讨论的 RSA-OAEP 填充方案）中，**掩码**是指利用公开的掩码生成函数（MGF）产生的伪随机比特串，通过按位异或（XOR）操作将其与目标数据块混合，从而消除数据块中任何可识别的结构化模式的技术手段。

为了严谨理解其工程实质，可以从以下三个层面解析：

**1. 操作机制（代数定义）**
掩码操作的本质是异或变换。设待处理的数据块为 $X$，掩码生成函数 $MGF$ 以随机种子 $Seed$ 为输入，输出与 $X$ 等长的伪随机串 $Mask = MGF(Seed)$。则掩码后的输出 $Y$ 定义为：

$$
Y = X \oplus Mask
$$

在 OAEP 流程中，该操作应用两次：

- 对数据块 $DB$（含填充位和消息）掩码：$\text{maskedDB} = DB \oplus MGF(Seed)$
- 对种子 $Seed$ 本身掩码：$\text{maskedSeed} = Seed \oplus MGF(\text{maskedDB})$

**2. 安全功能（设计目标）**
掩码不提供基于数学困难性的保密性（它是线性可逆的），其贡献在于**随机化预处理**：

- **破坏先验结构**：原始 $DB$ 中通常含有大量已知固定字节（如高位 `0x00`）。若直接送入 RSA 加密，这些固定模式将保留至密文中，使攻击者能通过离线枚举明文构建匹配表。掩码将结构化信息打散为均匀分布，使 $Y$ 在统计上与真随机数不可区分。
- **实现概率加密**：由于每次加密独立选取随机 $Seed$，生成的 $Mask$ 每次皆异。即使同一明文 $M$ 被多次加密，经掩码后的 $EM$ 截然不同，从而阻断选择明文攻击下的确定性映射路径。

**3. 解密端的还原（逆操作）**
因为异或运算满足自逆性（$A \oplus B \oplus B = A$），所以掩码是可完全恢复的线性变换。合法接收方从密文中解出 $\text{maskedSeed}$ 和 $\text{maskedDB}$ 后，重构流程如下：

- 恢复种子：$Seed = \text{maskedSeed} \oplus MGF(\text{maskedDB})$
- 恢复数据块：$DB = \text{maskedDB} \oplus MGF(Seed)$

该过程仅涉及哈希或伪随机函数计算，不依赖私钥的数学求逆，计算成本极低。

**4. 概念边界（与其它“掩码”的区分）**
需注意语境差异：在当前公钥密码学教材的 OAEP 协议层，掩码专指上述基于 MGF 的异或随机化。这与硬件安全中的“掩码”（将中间值拆分为多个随机分片 $K = K_1 \oplus K_2$ 以防御功耗分析）在数学构造和防御目标上完全不同，后者属于实现层抗侧信道技术。在本章范围内，统一理解为 **“利用伪随机串遮盖原始数据格式的预处理步骤”** 即可。
