# 第10章 其他公钥密码体制 — 章末学习目标自检

---

## 1. 能写出 DH 密钥交换的全过程，并说明为何 $\alpha^{X_A X_B} \bmod q$ 是双方共享的密钥。

**公开参数**：大素数 $q$ 及其本原根 $\alpha$（双方已知）。

| 步骤 | Alice | Bob |
|------|-------|-----|
| 选私钥 | 随机选 $X_A < q$，保密 | 随机选 $X_B < q$，保密 |
| 算公钥 | $Y_A = \alpha^{X_A} \bmod q$，公开 | $Y_B = \alpha^{X_B} \bmod q$，公开 |
| 交换 | 将 $Y_A$ 发给 Bob | 将 $Y_B$ 发给 Alice |
| 算共享密钥 | $K = (Y_B)^{X_A} \bmod q$ | $K = (Y_A)^{X_B} \bmod q$ |

双方得到相同密钥，因为模幂运算满足交换律：

$$K = (\alpha^{X_B})^{X_A} \bmod q = \alpha^{X_B X_A} \bmod q = \alpha^{X_A X_B} \bmod q = (\alpha^{X_A})^{X_B} \bmod q$$

攻击者只能观察到 $q, \alpha, Y_A, Y_B$，要得到 $K$ 必须求出 $X_A$ 或 $X_B$，即求解离散对数 $X_B = \operatorname{dlog}_{\alpha,q}(Y_B)$，这在 $q$ 足够大时计算上不可行。

**教材示例**：$q=353, \alpha=3$，$X_A=97, X_B=233$。$Y_A=3^{97}\bmod 353=40$，$Y_B=3^{233}\bmod 353=248$。双方计算 $K=248^{97}\bmod 353=40^{233}\bmod 353=160$。

## 2. 能解释离散对数的定义，以及它为何是 DH 安全性的基础。

对素数 $p$ 的本原根 $a$，幂 $a, a^2, \ldots, a^{p-1} \bmod p$ 恰为 $1$ 到 $p-1$ 的一个排列。对任意 $b \in [1, p-1]$，存在唯一指数 $i$（$0 \leq i \leq p-1$）使：

$$b \equiv a^i \pmod{p}$$

$i$ 称为 $b$ 以 $a$ 为底模 $p$ 的**离散对数**，记为 $\operatorname{dlog}_{a,p}(b) = i$。

**正向容易**：给定 $a, i, p$，用快速幂计算 $a^i \bmod p$ 只需 $O(\log i)$ 次模乘。

**逆向困难**：给定 $a, b, p$，求 $i$ 没有已知的多项式时间算法。已知最好的通用算法（数域筛法）的复杂度是亚指数级的。

DH 密钥交换的安全性正基于此：攻击者知道 $Y_A = \alpha^{X_A} \bmod q$ 和 $Y_B = \alpha^{X_B} \bmod q$，但无法在合理时间内求出 $X_A$ 或 $X_B$，因此无法计算 $\alpha^{X_A X_B} \bmod q$。这就是计算 DH 问题（CDH）的困难性。

## 3. 能逐步骤描述中间人攻击如何通过两对密钥分别欺骗 Alice 和 Bob。

简单 DH 协议不认证通信方，攻击者 Darth 可分别与双方建立独立密钥：

1. Darth 准备两对密钥 $(X_{D1}, Y_{D1})$ 和 $(X_{D2}, Y_{D2})$。
2. Alice 发送 $Y_A$ 给 Bob，Darth 截获，将 $Y_{D1}$ 发给 Bob；同时 Darth 计算 $K_2 = Y_A^{X_{D2}} \bmod q$（与 Alice 共享的密钥）。
3. Bob 收到 $Y_{D1}$，计算 $K_1 = Y_{D1}^{X_B} \bmod q$（以为是和 Alice 共享的，实际是和 Darth）。
4. Bob 发送 $Y_B$ 给 Alice，Darth 截获，将 $Y_{D2}$ 发给 Alice；同时 Darth 计算 $K_1 = Y_B^{X_{D1}} \bmod q$（与 Bob 共享的密钥）。
5. Alice 收到 $Y_{D2}$，计算 $K_2 = Y_{D2}^{X_A} \bmod q$（以为是和 Bob 共享的）。

结果：Alice 与 Darth 共享 $K_2$，Bob 与 Darth 共享 $K_1$。此后 Darth 可以解密 Alice 的消息、阅读/篡改后用 $K_1$ 重新加密发给 Bob，反之亦然，而双方都以为在直接安全通信。

防御方法：用数字签名或公钥证书认证公钥的归属。

## 4. 能写出 ElGamal 的密钥生成、加密（含一次密钥 $k$）和解密公式，并解释 $K^{-1}$ 的作用。

**密钥生成（Alice）**：
- 全局参数：素数 $q$ 及其本原根 $\alpha$。
- 选私钥 $X_A$（$1 < X_A < q-1$），保密。
- 公钥 $Y_A = \alpha^{X_A} \bmod q$，公开 $\{q, \alpha, Y_A\}$。

**加密（Bob 给 Alice 发消息 $M$）**：
- 选随机一次性整数 $k$（$1 \leq k \leq q-1$，每次加密都换）。
- 计算一次密钥 $K = (Y_A)^k \bmod q$。
- 密文为一对值：

$$C_1 = \alpha^k \bmod q, \quad C_2 = KM \bmod q$$

**解密（Alice）**：
- 由 $C_1$ 和私钥恢复 $K = (C_1)^{X_A} \bmod q$（因为 $C_1^{X_A} = \alpha^{k X_A} = Y_A^k = K$）。
- 求 $K$ 在模 $q$ 下的乘法逆元 $K^{-1}$，恢复明文：

$$M = C_2 \cdot K^{-1} \bmod q$$

**$K^{-1}$ 的作用**：加密时 $C_2 = K \cdot M \bmod q$，即用 $K$ 乘掩蔽了明文。解密时必须"除以 $K$"，即乘以 $K^{-1}$，才能消去掩蔽恢复 $M$。$C_1$ 的作用是将随机数 $k$ 以离散指数形式传给 Alice，使她能用私钥算出同一个 $K$。

**教材示例**：$q=19, \alpha=10, X_A=5, Y_A=3$。Bob 发 $M=17$，选 $k=6$：$K=3^6\bmod 19=7$，$C_1=10^6\bmod 19=11$，$C_2=7\times17\bmod 19=5$。Alice：$K=11^5\bmod 19=7$，$K^{-1}=11$，$M=5\times11\bmod 19=17$。

## 5. 能在实数域椭圆曲线上用几何方式说明点加和倍点的规则，并写出代数公式。

椭圆曲线方程（简化形式）：$y^2 = x^3 + ax + b$，条件 $4a^3 + 27b^2 \neq 0$ 保证曲线无奇点。曲线上所有点加上无穷远点 $O$ 构成交换群 $E(a,b)$。

**基本规则**：若曲线上三点共线，则它们之和为 $O$。

- **单位元**：$O$ 是加法单位元，$P + O = P$。
- **负元**：$P = (x_P, y_P)$ 的负元为 $-P = (x_P, -y_P)$（关于 $x$ 轴对称），$P + (-P) = O$。
- **点加 $P + Q$（$P \neq \pm Q$）**：过 $P, Q$ 画直线，交曲线于第三点 $R$，则 $P + Q = -R$（取 $R$ 关于 $x$ 轴的对称点）。
- **倍点 $2P$**：过 $P$ 画切线，交曲线于另一点 $R$，则 $2P = -R$。

**代数公式**：设 $P + Q = (x_R, y_R)$，

$$x_R = \lambda^2 - x_P - x_Q, \quad y_R = \lambda(x_P - x_R) - y_P$$

其中斜率：

$$\lambda = \begin{cases} (y_Q - y_P)/(x_Q - x_P), & P \neq Q \\ (3x_P^2 + a)/(2y_P), & P = Q \text{（切线斜率）} \end{cases}$$

标量乘法定义为重复加法：$kP = P + P + \cdots + P$（$k$ 次）。

## 6. 能在 $Z_p$ 椭圆曲线上完成模 $p$ 的点加运算（含求模逆元），并理解 $E_p(a,b)$ 的点数范围。

将曲线限制在有限域 $Z_p$ 上：$y^2 \bmod p = (x^3 + ax + b) \bmod p$，所有运算模 $p$。加法规则与实数域相同，但分数运算改为在 $Z_p$ 中求乘法逆元：

$$\lambda = \begin{cases} (y_Q - y_P)(x_Q - x_P)^{-1} \bmod p, & P \neq Q \\ (3x_P^2 + a)(2y_P)^{-1} \bmod p, & P = Q \end{cases}$$

$$x_R = (\lambda^2 - x_P - x_Q) \bmod p, \quad y_R = (\lambda(x_P - x_R) - y_P) \bmod p$$

负元：$-P = (x_P, -y_P \bmod p) = (x_P, p - y_P)$。

**教材示例**：$E_{23}(1,1)$，$P=(3,10), Q=(9,7)$：
- $\lambda = (7-10)(9-3)^{-1} \bmod 23 = (-3)(6)^{-1} \bmod 23$。$6^{-1} \bmod 23 = 4$（$6 \times 4 = 24 \equiv 1$），$\lambda = -3 \times 4 = -12 \equiv 11 \bmod 23$。
- $x_R = 11^2 - 3 - 9 = 121 - 12 = 109 \equiv 17 \bmod 23$。
- $y_R = 11(3-17) - 10 = 11(-14) - 10 = -164 \equiv 20 \bmod 23$。
- $P + Q = (17, 20)$。

**点数范围**（Hasse 定理）：

$$p + 1 - 2\sqrt{p} \leq N \leq p + 1 + 2\sqrt{p}$$

即 $E_p(a,b)$ 上点数约为 $p$ 个，与 $Z_p$ 元素数同阶。

## 7. 能区分 $Z_p$ 和 $GF(2^m)$ 上椭圆曲线方程和加法公式的不同。

| | $Z_p$（素数域） | $GF(2^m)$（二元扩域） |
|---|---|---|
| **方程** | $y^2 = x^3 + ax + b$ | $y^2 + xy = x^3 + ax^2 + b$（$b \neq 0$） |
| **负元** | $-P = (x_P, p - y_P)$ | $-P = (x_P, x_P + y_P)$ |
| **点加斜率** | $\lambda = (y_Q-y_P)(x_Q-x_P)^{-1} \bmod p$ | $\lambda = (y_Q+y_P)(x_Q+x_P)^{-1}$ |
| **点加 $x_R$** | $\lambda^2 - x_P - x_Q$ | $\lambda^2 + \lambda + x_P + x_Q + a$ |
| **点加 $y_R$** | $\lambda(x_P - x_R) - y_P$ | $\lambda(x_P + x_R) + x_R + y_P$ |
| **倍点斜率** | $(3x_P^2+a)(2y_P)^{-1}$ | $\lambda = x_P + y_P/x_P$ |
| **倍点 $x_R$** | $\lambda^2 - 2x_P$ | $\lambda^2 + \lambda + a$ |
| **倍点 $y_R$** | $\lambda(x_P - x_R) - y_P$ | $x_P^2 + (\lambda+1)x_R$ |

关键区别：在 $GF(2^m)$ 中减法等于加法（特征 2），方程含 $xy$ 项而非 $y^2$ 单独等于右侧，加法公式中所有减号变为加号，倍点公式完全不同。$GF(2^m)$ 上的运算在硬件中更易实现（无进位），适合受限环境。

## 8. 能写出 ECC Diffie-Hellman 密钥交换的私钥-公钥-共享密钥三段计算。

**公开参数**：椭圆群 $E_q(a,b)$、基点 $G$（$G$ 的阶 $n$ 为大素数，$nG = O$）。

| 步骤 | Alice | Bob |
|------|-------|-----|
| 私钥 | 随机选 $n_A < n$ | 随机选 $n_B < n$ |
| 公钥 | $P_A = n_A \times G$（点标量乘法） | $P_B = n_B \times G$ |
| 交换公钥 | 收到 $P_B$ | 收到 $P_A$ |
| 共享密钥 | $K = n_A \times P_B$ | $K = n_B \times P_A$ |

双方得到同一点：

$$n_A \times P_B = n_A \times (n_B \times G) = n_A n_B G = n_B \times (n_A \times G) = n_B \times P_A$$

通常取共享点 $K$ 的 $x$ 坐标作为对称会话密钥。

**安全性**基于椭圆曲线离散对数问题（ECDLP）：已知 $G$ 和 $P_A = n_A G$，求 $n_A$ 在计算上不可行。目前对 ECDLP 没有亚指数级通用算法，因此 ECC 可用比 RSA 短得多的密钥达到同等安全强度。

## 9. 能说明 ECC 加密/解密中 $kG$ 和 $P_m + kP_B$ 的作用，以及 Bob 如何用自己的私钥恢复 $P_m$。

**设置**：Bob 的私钥 $n_B$，公钥 $P_B = n_B \times G$。消息 $m$ 先编码为曲线上的点 $P_m$（不能简单取 $x$ 或 $y$ 坐标，因为不是所有坐标都在曲线上）。

**加密（Alice）**：选随机整数 $k$，密文为点对：

$$C_m = \{kG,\ P_m + kP_B\}$$

- $kG$ 的作用：将随机数 $k$ "打包"成曲线上的点传给 Bob，类似 ElGamal 中的 $C_1$。只有知道 $n_B$ 的人才能从中提取 $kP_B$。
- $P_m + kP_B$ 的作用：用 $kP_B$ 作为"掩蔽"加到消息点上，只有能算出 $kP_B$ 的人才能减去它恢复 $P_m$。

**解密（Bob）**：用私钥 $n_B$ 对第一个点做标量乘法得到 $n_B(kG) = k(n_B G) = kP_B$，然后从第二个点中减去：

$$(P_m + kP_B) - n_B(kG) = P_m + kP_B - kP_B = P_m$$

攻击者只知道 $kG$ 和 $P_B$，要算 $kP_B$ 需要解 ECDLP（由 $kG$ 求 $k$ 或由 $P_B, G$ 求 $n_B$），不可行。

## 10. 能概括 ECC 相比 RSA 的主要优势（更短密钥实现同等安全性）。

ECC 的核心优势是**在同等安全强度下密钥长度远短于 RSA**：

| 安全强度 | RSA 密钥长度 | ECC 密钥长度 |
|----------|-------------|-------------|
| 80 位 | 1024 | 160 |
| 128 位 | 3072 | 256 |
| 256 位 | 15360 | 512 |

原因：RSA 基于大整数分解问题，有数域筛法等亚指数级算法；而 ECC 基于椭圆曲线离散对数问题，目前最好的通用算法仍是完全指数级的（Pohlig-Hellman + Pollard rho，约 $O(\sqrt{n})$）。因此 ECC 密钥长度随安全强度增长慢得多。

更短密钥带来的实际好处：
- **计算更快、功耗更低**：适合智能卡、RFID、移动设备等资源受限环境；
- **存储和带宽节省**：证书和密钥更小；
- **每比特安全强度更高**。

ECC 已被纳入 IEEE P1363、ANSI、NIST 等标准，ECDH（密钥交换）和 ECDSA（数字签名）广泛应用于 TLS、区块链等场景。
