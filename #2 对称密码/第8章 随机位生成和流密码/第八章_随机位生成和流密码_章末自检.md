# 第8章 随机位生成和流密码 — 章末学习目标自检

---

## 1. 能区分统计随机性的均匀性、独立性与密码应用所需的不可预测性。

**统计随机性**是两个统计标准：

| 标准 | 含义 |
|------|------|
| **分布均匀性** | 位序列中 0 和 1 出现的频率大致相等（各约 1/2） |
| **独立性** | 序列的任意子序列不能由其他子序列推导。例如没有长度固定的可预测模式 |

统计测试（如 NIST SP 800-22 的频率测试、行程测试、Maurer 通用统计测试）可以检验均匀性，但**无法证明独立性**——只能发现不独立性。实践中用多个测试，若都未发现不独立，则对独立性建立信心。测试应满足均匀性、可伸缩性（对子序列也有效）、一致性（对所有种子性质一致）。

**不可预测性**是密码学的额外要求，与统计随机性不同：一个序列可以统计上看起来随机（0/1 各半、无明显模式），但如果它由确定性算法产生且种子可猜，则后续位完全可预测。密码应用（密钥生成、时变值、流加密）要求：
- **正向不可预测**：不知道种子时，即使知道前面任意多位，也不能以优于 1/2 的概率预测下一位。
- **反向不可预测**：不能由生成的输出反推种子。

真随机序列天然不可预测（各成员统计独立），但效率低；伪随机序列必须在算法层面保证不可预测性。

## 2. 能解释正向、反向不可预测性，并说明种子为何必须不可预测。

**正向不可预测性**：不知道种子的攻击者，即使看到了生成序列的前若干位（任意长度），也无法有效预测下一位。形式化定义为"通过下一位测试"：不存在多项式时间算法能以显著大于 1/2 的概率从已知前 $k$ 位预测第 $k+1$ 位。

**反向不可预测性**：攻击者不能从生成器的任何输出值（或输出序列的一段）反推出内部状态或种子。否则一旦种子泄露，整个序列（过去和未来）都被确定。

**种子必须不可预测的原因**：PRNG 是确定性算法——给定种子，输出完全确定。如果种子可预测（如用时间戳、进程 ID 等低熵来源），攻击者可以枚举或猜测种子，从而重现全部输出。种子本身必须是随机或伪随机数，SP 800-90A 推荐由 TRNG（真随机数生成器）产生种子后输入 PRNG。种子的熵决定了整个 PRNG 输出的安全上限——128 位种子最多提供 128 位安全性。

## 3. 能比较 TRNG、PRNG、PRF 的输入、确定性、输出长度与典型用途。

| 特性 | TRNG / NRBG | PRNG / DRBG | PRF |
|------|-------------|-------------|-----|
| **输入** | 物理熵源（热噪声、时钟抖动、键盘时序等） | 种子（+可能的上下文输入） | 种子 + 上下文相关输入 |
| **确定性** | 非确定性（每次不同） | 确定性（同种子同输出） | 确定性 |
| **输出长度** | 不限（但受熵源速率限制） | 不限长度的位流 | 固定长度（如 128 位） |
| **周期性** | 无周期 | 有周期（通常极长） | 不适用 |
| **速度** | 慢 | 快 | 快 |
| **典型用途** | 为 PRNG 生成种子、密码学密钥生成 | 流密码密钥流、会话密钥、随机数填充 | 对称密钥生成、时变值/nonce、消息认证中的伪随机输出 |

TRNG 不直接替代 PRNG 的原因：① 流密码需要与消息等长的密钥流，直接用 TRNG 必须安全分发整条密钥流，而 PRNG 只需共享短密钥；② TRNG 输出可能有偏差，需调节；③ TRNG 速率可能不满足应用需求。实际系统常将 TRNG 作为种子源，PRNG 作为高速输出来源，二者组合使用。

## 4. 能说明线性同余生成器为什么可用于统计仿真却不适用于密码学。

线性同余生成器（LCG）由四个参数决定：

$$X_{n+1} = (aX_n + c) \bmod m$$

其中 $m$ 为模，$a$ 为乘数，$c$ 为增量，$X_0$ 为种子。若参数选得好（如 $m = 2^{31}-1$ 为素数、$c = 0$、$a = 16807$），可达到全周期 $m-1$，序列统计性质良好，且可用 32 位算术高效实现。这使它适合统计抽样、仿真、游戏等非密码用途。

**不适合密码学的原因**：
1. **完全确定性**：给定种子即确定整个序列，没有前向/后向不可预测性。
2. **参数可被破解**：即使攻击者不知道参数，只要观察到少量连续输出，就能解出 $a, c, m$（因为递推是线性的）。
3. **已知一个值即可预测后续**：如果知道算法和参数，看到任意一个 $X_n$ 就能算出 $X_{n+1}, X_{n+2}, \ldots$。

LCG 不满足密码安全 PRNG 的核心要求——通过下一位测试。

## 5. 能写出 BBS 的初始化、平方迭代和最低位输出，并说明其安全性基础。

**BBS（Blum-Blum-Shub）**是密码安全伪随机位生成器（CSPRBG）。

**初始化**：选择两个大素数 $p, q$，满足 $p \equiv q \equiv 3 \pmod{4}$（即 Blum 素数），令 $n = pq$。选取与 $n$ 互素的随机种子 $s$，计算：

$$X_0 = s^2 \bmod n$$

**迭代与输出**：

$$X_i = X_{i-1}^2 \bmod n, \quad B_i = X_i \bmod 2$$

每轮取状态 $X_i$ 的**最低有效位**作为输出位。

**安全性基础**：BBS 的安全性基于**大整数分解难题**——求 $X_i$ 的模 $n$ 平方根（即逆向迭代）等价于分解 $n = pq$。只要 $n$ 足够大使得分解不可行，BBS 就能通过下一位测试：不存在多项式时间算法能以显著大于 1/2 的概率从前 $k$ 位预测第 $k+1$ 位。$p \equiv q \equiv 3 \pmod{4}$ 的条件保证每个二次剩余有唯一的平方根仍是二次剩余，使迭代方向唯一确定。

BBS 安全性强但速度较慢（每步需要大整数模平方），适合对安全性要求极高但吞吐量要求不高的场景。

## 6. 能说明 CTR-PRNG 与 OFB-PRNG 的状态更新区别，以及 CTR_DRBG 的初始化、生成、补种过程。

用分组密码构造 PRNG，种子由密钥 $K$ 和状态值 $V$ 组成（如 AES-128 中各 128 位）。

| 模式 | 状态更新 | 输出 |
|------|----------|------|
| **CTR-PRNG** | $V = (V + 1) \bmod 2^{128}$（计数器递增） | $E(K, V)$ |
| **OFB-PRNG** | $V = E(K, V)$（输出反馈，状态自身加密） | $V$（即新状态） |

CTR 模式中计数器递增后加密，OFB 模式中状态被加密结果替换。

**NIST CTR_DRBG**（使用 3DES 或 AES）三阶段：

1. **初始化**：用任意初始 $(K, V)$ 以 CTR 方式生成至少 seedlen 位（seedlen = keylen + outlen），将输出最高 seedlen 位与熵源提供的 seedlen 位 XOR，形成新种子。高 keylen 位为新 $K$，低 outlen 位为新 $V$。
2. **生成**：固定 $K$，每输出一块后 $V$ 递增，连续输出 $E(K, V)$。
3. **补种（reseed）**：当输出块数达到 reseed_interval 上限时，调用更新函数，用新熵位产生新的 $(K, V)$，然后继续生成。这限制了同一状态下输出的位数，降低状态被推导的风险。

## 7. 能描述典型流密码的状态、状态转换函数、输出函数、密钥和 IV 的关系。

流密码可视为一次一密的**伪随机版本**：用短密钥通过确定性算法生成与消息等长的伪随机密钥流，再与明文 XOR。

典型结构包含：
- **秘密状态** $s_i$：随时间演化的内部状态，初始由密钥 $K$ 加载。
- **状态转换函数** $f$：$s_{i+1} = f(s_i, K)$，驱动状态向前演化。
- **输出函数** $g$：$z_i = g(s_i, K)$，从当前状态产生密钥流位。
- **密钥 $K$**：初始化状态，决定整个密钥流。
- **初始向量 IV**（可选）：与密钥一起初始化状态。IV 不需保密，但应不可预测且每次唯一。

加解密：$c_i = z_i \oplus m_i$，$m_i = z_i \oplus c_i$（同一密钥流用于加密和解密）。

设计要求：密钥流周期长；密钥流统计上接近真随机（0/1 频率均匀）；密钥至少 128 位；**同一密钥绝不能加密两个不同明文**——否则两密文 XOR 即得两明文 XOR，极大简化密码分析。

## 8. 能说明流密码不能重用同一密钥的原因，并概述 RC4 的状态初始化和流生成。

**不能重用密钥的原因**：若用同一密钥流 $z$ 加密两个明文 $m_1, m_2$，得到 $c_1 = z \oplus m_1$，$c_2 = z \oplus m_2$。攻击者截获 $c_1, c_2$ 后计算 $c_1 \oplus c_2 = m_1 \oplus m_2$，密钥流被消去。两个明文的 XOR 可利用自然语言统计规律、已知明文片段等手段恢复出两个明文。这是一次一密和所有流密码的铁律。

**RC4**：Ron Rivest 1987 年设计，面向字节操作，变密钥长度。

**状态初始化**：使用 256 字节状态向量 $S$（初始为 $0, 1, \ldots, 255$ 的排列）和临时向量 $T$（密钥循环复制）。

```c
j = 0;
for (i = 0; i < 256; i++) {
    j = (j + S[i] + T[i]) mod 256;
    Swap(S[i], S[j]);
}
```

**流生成**（初始化后不再使用输入密钥）：

```c
i = (i + 1) mod 256;
j = (j + S[i]) mod 256;
Swap(S[i], S[j]);
t = (S[i] + S[j]) mod 256;
k = S[t];
```

输出字节 $k$ 与明/密文字节 XOR。RC4 算法简单、软件实现快，但密钥调度存在已知偏差，RFC 7465 已禁止 TLS 使用 RC4，NIST 也禁止其用于政府 TLS。

## 9. 能说明 LFSR 最大周期、其作为单独流密码的不安全性，以及 LFSR 与 NFSR 结合的动机。

**LFSR（线性反馈移位寄存器）**由 $n$ 个 1 位存储单元组成，每次时钟最低位移出为输出，其他位右移，新最高位由其他位的 XOR 计算：

$$B_n = \sum_{i=1}^{n} A_i B_{n-i} \pmod{2}$$

其特征多项式为 $P(X) = 1 + \sum_{i=1}^{n} A_i X^i$。当特征多项式是**本原多项式**时，$n$ 位 LFSR 达到最大周期 $2^n - 1$（m 序列），统计性质良好（0/1 均匀、游程分布理想），硬件实现极其紧凑高效。

**单独使用不安全**：
- 反馈函数已知时，连续 $n$ 位输出即可确定全部状态和后续所有位。
- 反馈函数未知时，观察 $2n$ 位输出也足以通过线性代数解出反馈系数。
- 本质上是线性系统，易受相关攻击和代数攻击。

**NFSR（非线性反馈移位寄存器）**的反馈函数包含非线性项（如 AND：$B_4 = B_0 \oplus B_1 B_3$），引入非线性使密码分析困难。但 NFSR 缺乏成熟的周期和安全性理论。

**结合动机**：将 LFSR 与 NFSR 组合（如 Grain-128a），用 LFSR 保证长周期和输出统计平衡性，用 NFSR 和非线性滤波函数提供密码学强度。LFSR 输出还可掩蔽 NFSR 输入，使 NFSR 状态保持平衡。

## 10. 能解释偏差、熵率、调节和两类噪声源健康测试的作用。

**偏差（Bias）**：熵源各可能输出的概率不相等。例如 TRNG 输出中 1 的比例偏多，或物理噪声叠加了周期性信号导致统计上可检测的规律。偏差使实际熵低于理想值。

**熵率（Entropy Rate）**：熵源每输出位提供的熵量，等于评估的最小熵位数除以输出总位数，取值 $[0, 1]$。无偏且各位独立的位流熵率为 1。对长度 $n$、最小熵 $k$ 的源，熵率为 $k/n$。

**调节（Conditioning / 偏差校正）**：用密码算法（哈希函数或对称分组密码）处理 TRNG 原始输出，消除偏差、提高熵质量。方法包括：
- **哈希调节**：将 $m \geq n$ 个输入位通过哈希函数取 $n$ 位输出。
- **hash_df**：以计数器、输出长度和输入串为哈希输入，连接多个哈希输出后取高位。
- **分组密码调节**：用 AES/CBC 或 CMAC 处理 TRNG 位（如英特尔 DRNG 用 CMAC）。

**两类噪声源健康测试**（SP 800-90B）：

| 测试 | 作用 |
|------|------|
| **重复计数测试** | 检测噪声源是否卡在某个固定值（灾难性故障）。若连续 $C$ 个相同样本则报警，$C = \lceil 1 + (-\log W)/H \rceil$，$W$ 为可接受假阳性概率，$H$ 为每样本最小熵 |
| **自适应比例测试** | 在连续样本窗口内检测某一样本出现过于频繁，发现大的熵损失 |

对调节函数输出还应做 SP 800-22 随机性测试，确认其表现为真随机位流。

## 11. 能概括英特尔 DRNG 的热噪声、CMAC 调节、CTR_DRBG 三阶段结构，以及 RDRAND、RDSEED 的用途。

英特尔 DRNG（2012 年起在多核芯片中部署）全硬件实现、与处理器同芯片，三阶段结构：

1. **熵源（热噪声）**：两个相互馈电的反相器工作在不稳定状态，由热噪声驱动产生随机位，速率可达 4 Gbps。
2. **调节（CMAC）**：每次收集 512 位原始熵，用 AES-CBC-MAC/CMAC 调节，输出 256 位高质量、无偏的真随机位。
3. **PRNG（CTR_DRBG）**：以 256 位调节结果为种子，用 CTR 模式 AES 高速生成伪随机数。每个种子可生成 511 个 128 位样本后重新补种。

**两条指令**：

| 指令 | 来源 | 用途 |
|------|------|------|
| **RDRAND** | CTR_DRBG 阶段输出 | 提供 16/32/64 位符合密码学标准的伪随机数，适用于大多数应用（密钥生成、随机化等），速度快 |
| **RDSEED** | 调节器/增强 NRBG 输出 | 提供高质量熵源种子，用于为其他 PRNG（包括软件 DRBG）播种，速度较慢但熵值更高 |

架构上 TRNG 提供种子、PRNG 提供高速输出的组合，兼顾了安全性和性能。
