# 一、概念总览与核心分类维度

本文辨析五个密码学高频基础概念，核心区分维度为：是否为确定性算法、是否为标准化密码原语、是否具备形式化安全定义、输入输出结构、应用场景。

基础分类边界：

1. 非确定性随机生成器：TRNG（唯一物理真随机）

2. 确定性随机生成器（工程大类）：PRNG（包含安全与不安全实现）

3. 确定性安全随机生成器（密码学子集）：CSPRNG、PRG

4. 确定性密码函数原语（独立维度）：PRF

# 二、各概念精确定义与核心特征

## 1. TRNG 真随机数生成器

**定义**：基于物理熵源（热噪声、时钟抖动、物理噪声等）生成随机序列的非确定性随机生成器。

**核心特征**：

- 非确定性：相同初始条件下，两次输出结果不同，无固定算法映射关系
    
- 输出为信息论安全的真随机序列，无多项式时间算法可预测、区分
    
- 生成速率低、开销大，无法大批量生成随机比特
    

**安全属性**：信息论安全（无条件安全）

**定位与用途**：仅用于生成高可信原始熵、种子、初始向量 IV，不直接用于生成加密密钥流

## 2. PRNG 伪随机数生成器

**定义**：工程层面通用概念，所有能够通过确定性算法、基于种子或内部状态，生成近似随机数字/比特序列的算法统称，无统一形式化安全定义。

**核心特征**：

- 完全确定性：相同种子/内部状态，必然输出完全相同的随机序列
    
- 仅要求统计随机性（均匀、无周期规律），不强制密码学安全
    
- 包含两类实现：不安全普通 PRNG、安全 CSPRNG
    

**安全属性**：无统一安全标准，普通 PRNG 可被多项式时间算法破解预测

**典型实例**：LCG 线性同余生成器、MT 19937 梅森旋转算法

## 3. CSPRNG 密码学安全伪随机数生成器

**定义**：PRNG 的安全子集，满足密码学安全要求的确定性伪随机生成器，是工程落地的安全随机源。

**核心特征**：

- 属于确定性 PRNG，继承 PRNG 的确定性特征
    
- 满足计算不可区分性：PPT 敌手无法区分其输出与真随机序列
    
- 多为有状态设计，可持续接收外部熵更新内部状态，长期输出安全随机序列
    

**安全属性**：计算安全（多项式时间不可区分）

**典型实例**：操作系统随机源/dev/urandom、工程加密专用随机生成器

## 4. PRG 伪随机生成器

**定义**：密码学理论标准化原语，是严格无状态、可证明安全的伪随机扩展算法，形式化定义为 $G:\{0,1\}^n \rightarrow \{0,1\}^m，m\gg n$。

**核心特征**：

- 确定性、无状态：仅输入短均匀随机种子，无额外外部输入、无内部状态更新
    
- 强制长度扩展：输出比特长度远大于输入种子长度
    
- 具备严格形式化安全游戏：PPT 敌手无法区分 PRG 输出与均匀真随机串
    

**安全属性**：计算安全（标准 PRG 不可区分游戏）

**定位与用途**：流密码核心组件，用于由短密钥种子生成长密钥流

## 5. PRF 伪随机函数

**定义**：密码学核心基础原语，带密钥的确定性函数，形式化定义为 $F:\mathcal{K} \times \{0,1\}^n \rightarrow \{0,1\}^m$。

**核心特征**：

- 双输入结构：秘密密钥 $k$ + 公开可自适应选择的外部输入 $x$
    
- 无长度扩展要求：输入输出长度可相等（如 AES 输入输出均为 128 bit）
    
- 支持多次自适应查询：敌手可任意选择不同输入 $x$ 进行查询
    
- 安全标准严格：无法区分伪随机函数输出与完全随机函数输出
    

**安全属性**：计算安全（PRF 自适应区分游戏）

**典型实例**：AES 分组密码、HMAC

# 三、核心集合与推导关系（考试核心）

## 1. 层级包含关系

PRG $\subsetneq$ CSPRNG $\subsetneq$ PRNG

- 所有 PRG 都是 CSPRNG，所有 CSPRNG 都是 PRNG
    
- 逆命题不成立：PRNG 不一定是 CSPRNG，CSPRNG 不一定是 PRG
    
- TRNG 完全独立于所有 PRNG 体系，无交集
    

## 2. 原语推导构造关系

- PRF 可以构造 PRG/CSPRNG：将 PRF 输入设置为递增计数器，拼接多次输出，实现长度扩展，生成密钥流（CTR 模式核心原理）
    
- 普通 PRNG/CSPRNG 无法直接构造 PRF：无任意外部输入接口，不满足 PRF 的函数查询特性
    
- PRG 无法直接构造 PRF：无外部可控输入参数，仅依赖固定种子
    
- TRNG 为所有确定性随机原语提供可信种子熵源
    

# 四、关键维度横向对比表

|概念|确定性|状态特性|形式化安全定义|长度扩展|核心输入|安全等级|
|---|---|---|---|---|---|---|
|TRNG|否|无状态（物理随机）|无|不涉及|物理熵源|信息论安全|
|PRNG|是|多为有状态|无|可选|种子/内部状态|良莠不齐|
|CSPRNG|是|多为有状态|有|可选|种子+熵更新|计算安全|
|PRG|是|无状态|有（严格）|必须扩展|唯一短种子|计算安全|
|PRF|是|无状态|有（严格）|无需扩展|密钥+任意输入 x|计算安全|

# 五、高频易错判断题总结

1. TRNG 是 CSPRNG/PRNG/PRG。（错误，TRNG 为非确定性，不属于伪随机体系）

2. 所有 PRNG 都是密码学安全的。（错误，普通 PRNG 仅满足统计随机，无密码学安全）

3. 所有 PRG 都是 CSPRNG，所有 CSPRNG 都是 PRNG。（正确）

4. CSPRNG 都是 PRG。（错误，CSPRNG 多为有状态，PRG 为无状态理论原语）

5. PRF 可以通过计数器迭代构造安全随机位流。（正确，CTR 模式核心原理）

6. PRG 可以直接作为 PRF 使用。（错误，PRG 无可控外部输入 x，不支持自适应查询）

7. 存在不安全的 PRG。（错误，PRG 定义自带安全属性，不安全的随机生成器不能称为 PRG）

# 六、核心应用链路总结

TRNG 生成高可信种子 → 输入 PRF/AES → 计数器迭代生成 PRG 密钥流 → 密钥流与明文异或 → 流加密完成
