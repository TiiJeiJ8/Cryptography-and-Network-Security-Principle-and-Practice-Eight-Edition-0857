## 1. 能否说明对称加密方案的 5 个基本成分，并写出 $Y=E(K,X)$ 与 $X=D(K,Y)$ 的含义？

对称加密方案的 5 个基本成分：

| 成分 | 教材说明 |
|------|----------|
| **明文** | 可理解的原始消息或数据 $X = [X_1, X_2, \ldots, X_M]$，是算法的输入 |
| **加密算法** | 对明文进行各种代替和变换 |
| **密钥** | $K = [K_1, K_2, \ldots, K_J]$，也是算法的输入，独立于明文和算法；具体代替和变换依赖密钥 |
| **密文** | $Y = [Y_1, Y_2, \ldots, Y_N]$，算法的输出，看起来随机且杂乱，依赖于明文和密钥 |
| **解密算法** | 本质上是加密算法的逆运算；输入密文和密钥，输出原始明文 |

数学表示：
- $Y = E(K, X)$：用密钥 $K$ 和加密算法 $E$ 对明文 $X$ 加密，产生密文 $Y$。
- $X = D(K, Y)$：用同一密钥 $K$ 和解密算法 $D$ 对密文 $Y$ 解密，恢复明文 $X$。

安全性要求：即使敌手知道算法 $E$、$D$ 并获得密文，没有密钥 $K$ 也无法恢复明文或算出密钥。

## 2. 能否解释为什么传统密码不要求算法保密，而要求密钥保密？

这就是密码学中的 **Kerckhoffs 原则**。教材给出传统密码安全使用的两个要求：

1. **加密算法必须足够强**——即使敌手知道算法并得到若干密文，甚至拥有一定数量的明密文对，也不能破译密文或算出密钥。
2. **发送方和接收方必须以安全形式获得密钥并保证密钥安全**——如果有人发现密钥且知道算法，就能解读用该密钥加密的所有通信。

教材明确强调：**不需要算法保密，只需要密钥保密**。原因在于：
- 算法公开可经受广泛密码分析审查，有助于发现弱点并改进；
- 算法的分发和更新代价高（需嵌入软硬件），而密钥可以频繁更换；
- 一旦密钥泄露，更换密钥即可；若算法泄露则需要更换整个系统。

对称密码的首要安全问题是**密钥的保密性**，而非算法的保密性。

## 3. 能否从运算类型、密钥数和处理明文方法三个角度分类密码编码系统？

| 分类角度 | 类别 | 说明 |
|----------|------|------|
| **运算类型** | 代替（Substitution） | 把明文元素映射为另一个元素（改变字母值） |
| | 置换（Permutation） | 重新排列明文元素的位置（不改变字母值） |
| | 乘积密码 | 多层代替和置换组合，大多数现代密码使用 |
| **密钥数** | 对称密码（单密钥/秘密钥/传统密码） | 发送方和接收方使用**相同**密钥 |
| | 非对称密码（双密钥/公钥密码） | 发送方和接收方使用**不同**但相关的密钥 |
| **处理明文方法** | 分组密码 | 每次处理输入的一组元素（一个分组），输出一组元素 |
| | 流密码 | 连续处理输入元素，每次输出一个元素 |

基本要求：所有运算必须可逆，不允许丢失信息。

## 4. 能否区分密码分析学攻击与穷举攻击，并说明穷举攻击为什么还需要识别明文？

| 攻击方法 | 教材说明 | 核心思路 |
|----------|----------|----------|
| **密码分析学攻击** | 依赖于算法的性质、明文的一般特征或某些明密文对，企图利用算法特征推导特定明文或使用的密钥 | 利用结构、统计规律、已知信息进行推理 |
| **穷举攻击** | 对一条密文尝试所有可能的密钥，直到把它转换为可读、有意义的明文 | 暴力遍历密钥空间，平均需试一半密钥 |

**穷举攻击为什么还需要识别明文**：尝试每个密钥后都会得到一个"解密结果"，但分析者必须能判断哪个结果才是真正的明文。若明文是英文散文，识别较容易（有意义的单词和语法）；若文本加密前已压缩，识别更困难；若是通用二进制数据且已压缩，自动识别更加困难。因此穷举攻击不仅需要算力，还需要**关于预期明文的知识**以及**从混淆中自动区分明文的方法**。

## 5. 能否按攻击者已知信息区分唯密文、已知明文、选择明文、选择密文和选择文本攻击？

| 攻击类型 | 密码分析者已知的信息 | 难度 |
|----------|---------------------|------|
| **唯密文攻击** | 加密算法；待解密文 | 最难（信息量最少） |
| **已知明文攻击** | 加密算法；待解密文；用**同一密钥**加密的一个或多个明密文对 | 较易 |
| **选择明文攻击** | 加密算法；待解密文；分析者**选择**的明文及对应密文（与待解密文同密钥） | 更易 |
| **选择密文攻击** | 加密算法；待解密文；分析者**选择**的密文及对应明文（与待解密文同密钥解密） | 更易 |
| **选择文本攻击** | 加密算法；待解密文；分析者选择的明文及对应密文；分析者选择的密文及对应明文 | 最易（信息最多） |

补充：与已知明文攻击紧密相关的是**可能词攻击**——分析者可能知道消息中某些固定内容（如会计文件开头的关键词、程序源代码中的版权信息）。选择明文攻击中，分析者会特意选取最有利于恢复密钥的数据。

## 6. 能否说明无条件安全与计算上安全的区别，并指出一次一密在本章中的特殊地位？

| 概念 | 教材定义 |
|------|----------|
| **无条件安全** | 无论有多少可用密文，如果都不足以**唯一确定**密文对应的明文，则称该密码体制无条件安全。无论花多少时间，攻击者都无法解密，因为所需信息根本不在密文中 |
| **计算上安全** | 若破译密码的**代价超过密文信息价值**，或破译密码的**时间超过密文信息有效生命期**，则称满足计算上安全 |

教材强调：**除一次一密外，所有加密算法都不是无条件安全的**。

一次一密（One-Time Pad）的特殊地位：
- 它是**唯一具有完善保密（perfect secrecy）**的密码体制，是真正无条件安全的。
- 产生的随机输出与明文没有任何统计关系，密文不包含明文的任何信息。
- 对任意与密文等长的明文，都存在一个密钥能产生该密文，分析者无法判断哪个是真的。
- 实际使用受限于：大规模真随机密钥生成困难、密钥分发和保护代价极高（每条消息需等长新密钥），因此主要用于安全性要求极高的低带宽信道。

## 7. 能否写出 Caesar 密码的一般加密式 $C=E(k,p)=(p+k)\bmod 26$ 和解密式 $p=D(k,C)=(C-k)\bmod 26$？

Caesar 密码是最简单的代替密码，将每个字母替换为字母表中其后第 $k$ 个字母（字母表循环，Z 之后是 A）。令 $a=0, b=1, \ldots, z=25$：

**加密**：
$$C = E(k, p) = (p + k) \bmod 26$$

**解密**：
$$p = D(k, C) = (C - k) \bmod 26$$

其中 $k \in \{1, 2, \ldots, 25\}$。原始 Caesar 密码取 $k=3$（A→D, B→E, ...）。

教材示例：$k=3$，明文 `meet me after the toga party` → 密文 `PHHW PH DIWHU WKH WRJD SDUWB`。

Caesar 密码密钥空间仅 25 个，极易穷举——只需测试 25 个密钥，且明文语言已知时意义易于识别。

## 8. 能否说明单表代替密码为什么虽然密钥空间大，却仍会暴露明文字母频率和多字母语法模式？

单表代替密码允许 26 个字母任意置换，密钥空间为 $26! > 4 \times 10^{26}$，看似巨大，但它**极易被频率分析攻击**。

根本原因：单表代替中，**每个明文字母固定映射到唯一的密文字母**。因此：
- 明文中字母的使用频率分布（如 e 最常见，约 12.7%；t、a、o、i、n、s、h、r 次之）完整地保留在密文中——密文中出现最多的字母很可能对应 e。
- 双字母组合频率（th 最常见，还有 he、in、er、an 等）和三字母组合（the、and、for 等）的统计规律也完整保留。
- 单词长度模式、空格位置等语言结构信息完全暴露。

教材示例分析过程：先统计密文字母频率猜测 e、t；再找最常见双字母组合 ZW 对应 th；由 ZWP 推测 the；逐步推导得到完整明文。

即使采用**同音词**方法（一个明文字母对应多个密文符号，数量与频率成正比）来破坏单字母频率信息，**多字母语法模式仍会残留**——因为每个明文元素仍然只影响一个密文位置。根本对策是多字母一起加密（如 Playfair、Hill）或多表代替（如 Vigenere）。

## 9. 能否根据教材例子说清 Playfair 密码矩阵构造方法和四条双字母加密规则？

**矩阵构造**（以密钥词 `monarchy` 为例）：
1. 将密钥词去重后从左到右、从上到下填入 $5 \times 5$ 矩阵。
2. 剩余字母按字母表顺序填入矩阵空位。
3. 字母 **I 和 J 合并为一格**（25 格放 26 个字母）。

以 `monarchy` 为密钥的矩阵：

| M | O | N | A | R |
|---|---|---|---|---|
| C | H | Y | B | D |
| E | F | G | I/J | K |
| L | P | Q | S | T |
| U | V | W | X | Z |

**明文预处理**：从左到右每两个字母一组。若一组内两字母相同，中间插入填充字母（如 x）后重新分组（如 `balloon` → `ba lx lo on`）。

**四条加密规则**（对每对明文字母）：
1. **同行**：各自由**右边**字母代替，最右边字母绕回该行最左边字母。
2. **同列**：各自由**下面**字母代替，最下面字母绕回该列最上面字母。
3. **矩形（既不同行也不同列）**：每个字母用其所在行与另一个字母所在列**交叉处**的字母代替（即交换列号）。
4. （预处理规则）相同字母对中间插入填充字母。

Playfair 有 $26 \times 26 = 676$ 个字母对，频率分析比单表困难得多，但仍保留明文语言的大部分结构特征，几百个字母的密文就足以破译。

## 10. 能否写出 Hill 密码的矩阵形式 $C=PK\bmod 26$，并说明解密为什么需要 $K^{-1}$？

Hill 密码将 $m$ 个连续明文字母替换为 $m$ 个密文字母，由 $m$ 个线性方程决定。用行向量表示：

$$C = PK \bmod 26$$

其中 $P = (p_1\ p_2\ \ldots\ p_m)$ 是明文行向量，$K$ 是 $m \times m$ 密钥矩阵，$C = (c_1\ c_2\ \ldots\ c_m)$ 是密文行向量，所有运算模 26。

以 $m=3$ 为例：
$$\begin{cases}
c_1 = (k_{11}p_1 + k_{21}p_2 + k_{31}p_3) \bmod 26 \\
c_2 = (k_{12}p_1 + k_{22}p_2 + k_{32}p_3) \bmod 26 \\
c_3 = (k_{13}p_1 + k_{23}p_2 + k_{33}p_3) \bmod 26
\end{cases}$$

**解密需要 $K^{-1}$** 的原因：解密要从 $C$ 恢复 $P$。因为 $C = PK$，两边右乘 $K^{-1}$ 得：

$$P = CK^{-1} \bmod 26 = PKK^{-1} = P$$

$K^{-1}$ 是密钥矩阵 $K$ 在模 26 下的逆矩阵，满足 $KK^{-1} = K^{-1}K = I$（单位矩阵）。没有 $K^{-1}$ 就无法逆转线性变换。逆矩阵存在的条件是 $\det(K)$ 与 26 互素（即 $\gcd(\det(K), 26) = 1$）。

## 11. 能否说明 Hill 密码为什么能隐藏单字母频率特性，又为什么容易被已知明文攻击破解？

**能隐藏单字母频率的原因**：Hill 密码中，每个密文字母是 $m$ 个明文字母的**线性组合**（模 26）。同一个明文字母在不同上下文中（即与不同的相邻字母组合时）会被映射为不同的密文字母。矩阵越大，混合的明文字母越多，隐藏的频率信息越多——$3 \times 3$ 的 Hill 密码不仅隐藏单字母频率，还隐藏双字母频率。这使得单字母频率分析完全失效。

**容易被已知明文攻击破解的原因**：Hill 密码是**线性变换**，结构完全由密钥矩阵 $K$ 决定。如果攻击者获得 $m$ 个长度为 $m$ 的明密文对，定义 $m \times m$ 矩阵 $X = (p_{ij})$（每行一个明文向量）和 $Y = (c_{ij})$（对应密文向量），则有：

$$Y = XK$$

若 $X$ 可逆（即 $\det(X)$ 与 26 互素），攻击者直接计算：

$$K = X^{-1}Y$$

就完全恢复了密钥。这比对抗频率分析容易得多。线性结构既是 Hill 密码隐藏频率的优点，也是它的致命弱点。

## 12. 能否写出 Vigenere 密码的加密式 $C_i=(p_i+k_{i\bmod m})\bmod 26$，并说明重复密文序列如何帮助推断密钥词长度？

Vigenere 密码是多表代替密码，使用 26 个 Caesar 表循环。设密钥词长度为 $m$，密钥 $K = k_0, k_1, \ldots, k_{m-1}$ 循环使用。

**加密公式**：
$$C_i = (p_i + k_{i \bmod m}) \bmod 26$$

**解密公式**：
$$p_i = (C_i - k_{i \bmod m}) \bmod 26$$

**重复密文序列推断密钥长度的原理**：
- 如果明文中两处出现**相同的字母序列**，且它们之间的距离恰好是密钥词长度 $m$ 的整数倍，那么这两处会使用**相同的密钥字母序列**加密，从而产生**相同的密文序列**。
- 反之，分析者在密文中发现重复出现的序列时，计算这些重复序列之间的距离，密钥词长度 $m$ 很可能是这些距离的**公因子**。
- 教材示例：密文中两次出现 `VTW`，间隔为 9，可推断密钥词长度为 3 或 9。

确定 $m$ 后，密码实际上分解为 $m$ 个独立的单表代替——位置 $0, m, 2m, \ldots$ 用同一个 Caesar 表，位置 $1, m+1, 2m+1, \ldots$ 用另一个，以此类推。对每组分别做单字母频率分析即可恢复每个密钥字母。

## 13. 能否写出 Vernam 密码的异或形式 $c_i=p_i\oplus k_i$ 与 $p_i=c_i\oplus k_i$？

Vernam 密码基于二进制数据运算，使用与明文等长的密钥，逐位异或：

**加密**：
$$c_i = p_i \oplus k_i$$

**解密**：
$$p_i = c_i \oplus k_i$$

其中 $p_i$ 是明文第 $i$ 个二进制位，$k_i$ 是密钥第 $i$ 个二进制位，$c_i$ 是密文第 $i$ 个二进制位，$\oplus$ 是异或（XOR）运算。

解密正确性来自异或的**自反性**：$c_i \oplus k_i = (p_i \oplus k_i) \oplus k_i = p_i \oplus (k_i \oplus k_i) = p_i \oplus 0 = p_i$。

Vernam 原方案使用循环密钥磁带，周期很长但仍可被足够密文加统计方法破解。Mauborgne 改进为一次一密（密钥真随机、不重复、用后即弃），才达到无条件安全。

## 14. 能否说明一次一密不可攻破所依赖的三个条件：密钥真正随机、与消息等长、只使用一次？

一次一密使用与消息一样长且无重复的随机密钥加密消息，密钥只用于一条消息后即丢弃。其不可攻破性依赖以下三个条件同时满足：

1. **密钥真正随机**：密钥位流必须是真随机的，与明文没有任何统计关系。若密钥有规律或可预测，分析者就有模式可循。
2. **密钥与消息等长**：密钥长度必须等于明文长度。若密钥短于明文，就不得不重复使用密钥（退化为 Vigenere 类密码），明文统计结构会泄露。
3. **密钥只使用一次**：每条消息使用一个全新的密钥，用后即弃。若同一密钥加密多条消息，分析者可将多条密文结合分析（如两条密文异或可消去密钥，暴露两条明文的异或关系）。

三个条件同时满足时，密文不包含明文的任何信息——对任意等长的候选明文，都存在一个密钥能产生给定密文，分析者无法判断哪个是真明文。这就是**完善保密**。

实际困难：大规模真随机密钥生成难；每条消息都需安全分发等长密钥，密钥管理代价极高。因此仅用于高安全低带宽信道。

## 15. 能否说明置换密码与代替密码的根本差异，并解释为什么单纯置换仍保留原始明文字母频率？

**根本差异**：
- **代替密码**：改变明文字母的**值**——将明文字母替换为其他字母、数字或符号（如 Caesar 密码中 a→D）。
- **置换密码**：不改变明文字母本身，只**重新排列字母的位置**——明文字母还是那些字母，只是顺序被打乱（如栅栏加密、列置换）。

**单纯置换保留原始明文字母频率的原因**：置换操作只改变字母的位置，不增加、删除或替换任何字母。密文中各字母出现的频次与明文完全相同——e 出现多少次，密文中 e 还是出现多少次。因此密文的字母频率分布与明文语言（如英语）的频率分布完全一致，分析者一眼就能看出这是英文文本的置换，频率分析（单字母、双字母、三字母组合）可直接用于推断排列规律。

这与代替密码形成对比：代替密码虽然也可能保留频率分布（单表代替），但至少字母身份被替换了；而置换密码连字母身份都没变，只是位置变了。教材指出单纯置换密码"对密码分析者来说微不足道"，但**多次置换**（用同一算法对密文再加密）可大幅增加分析难度。
