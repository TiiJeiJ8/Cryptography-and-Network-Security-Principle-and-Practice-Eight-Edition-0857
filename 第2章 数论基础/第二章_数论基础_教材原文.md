# 第 2 章 数论基础

## 学习目标

- 理解整除性和带余除法的概念
- 掌握欧几里得算法求最大公约数
- 了解模运算的概念
- 解释扩展欧几里得算法的用法
- 讨论素数的主要概念
- 理解费马定理
- 理解欧拉定理
- 掌握欧拉函数
- 解释中国剩余定理
- 掌握离散对数

在加密算法中，数论的应用非常广泛。为了让读者理解数论在密码学中的应用，本章提供广度和深度都足够的数论相关知识。熟悉这些内容的读者可略过本章。
前三节介绍有限域的基本概念，包括整除、欧几里得算法和模运算。读者既可以现在学习这些章节，又可以等到第5章介绍有限域时学习。
2.4节至2.8节讨论有关素数和离散对数的相关数论知识。这些知识是设计非对称（公钥）加密算法的基础。读者既可以现在学习这些内容，又可以等到介绍第三部分时学习。本章包含了大量的例子。

## 2.1 整除性和带余除法

### 2.1.1 整除性

设 $a,b,n$ 均为整数，若存在某个数 $n$ 使得 $a = nb$ 成立，则称非零数 $b$ 整除 $a$。换言之，若 $b$ 除 $a$ 没有余数，则认为 $b$ 整除 $a$。$b$ 除 $a$ 通常用 $b|a$ 来表示。同时，若 $b|a$，则称 $b$ 是 $a$ 的一个因子。

示例：24 的正因子有 $1,2,3,4,6,8,12,24$；$13|182$；$-5|20$；$17|289$；$-3|33$；$17|0$

随后，我们将用到整数整除的一些简单性质，如下所示：
1. 若 $a|1$，则 $a=\pm1$。
2. 若 $a|b$ 且 $b|a$，则 $a=\pm b$。
3. 任何不等于零的整数整除 $0$。
4. 若 $a|b$ 且 $b|c$，则 $a|c$。
    例：$11|66$ 且 $66|198 \implies 11|198$
5. 对任意整数 $m,n$，若 $b|g$ 且 $b|h$，则 $b|(mg+nh)$。
    证明：
    若 $b|g$，则存在整数 $g_1$，使得 $g = b\times g_1$。
    若 $b|h$，则存在整数 $h_1$，使得 $h = b\times h_1$。
    $$mg+nh = mbg_1+nbh_1 = b\times(mg_1+nh_1)$$
    得出 $b$ 整除 $mg+nh$。

示例：$7|14$ 且 $7|63$；$m=3;n=2$
要证明 $7|(3\times14+2\times63)$
有 $3\times14+2\times63 = 7\times(3\times2+2\times9)$
显然有 $7|7\times(3\times2+2\times9)$

### 2.1.2 带余除法

对给定的任意正整数 $n$ 和任意整数 $a$，若用 $n$ 除 $a$，得到整数商 $q$ 和整数余数 $r$，则满足以下关系式：
$$a = qn + r,\quad 0\le r < n;\ q=\lfloor a/n \rfloor \tag{2.1}$$
式中，$\lfloor x \rfloor$ 表示小于等于 $x$ 的最大整数。式(2.1)称为带余除法。

$a$ 一定落在轴上的某处（正数 $a$ 的情况如图 2.1 所示，类似地，$a$ 也可为负数）。从 0 开始，依次为 $n,2n$，直到 $qn$，使得 $qn \le a < (q+1)n$，其中 $qn$ 到 $a$ 的距离为 $r$。这样，就得到了唯一的 $q$ 和 $r$。余数 $r$ 通常称为剩余数。

示例：
$a=11;n=7;\ 11=1\times7+4;r=4,q=1$
$a=-11;n=7;\ -11=(-2)\times7+3;r=3,q=-2$

图2.1展示关系式 $a=qn+r,\ 0\le r<n$ 的数轴示意，包含通用关系、实例 $70=(4\times15)+10$。

## 2.2 欧几里得算法

欧几里得算法是数论中的一个最基本的技巧，它可以简单地求出两个正整数的最大公因子。首先，我们需要一个简单的定义：两个整数是互素的，当且仅当它们只有一个正整数公因子 1。

### 2.2.1 最大公因子

前面讲过，对整数 $a,b,m$，若存在 $m$ 满足 $a=mb$，则称非零整数 $b$ 是 $a$ 的一个因子。用 $\gcd(a,b)$ 表示 $a$ 和 $b$ 的最大公因子（GCD）。$a$ 和 $b$ 的最大公因子是能同时整除 $a$ 和 $b$ 的最大整数。另外，定义 $\gcd(0,0)=0$。

更正式描述，正整数 $c$ 称为 $a$ 和 $b$ 的最大公因子，若：
1. $c$ 是 $a$ 和 $b$ 的因子。
2. $a$、$b$ 的公因子都是 $c$ 的一个因子。

另一个等效的定义如下：
$$\gcd(a,b)=\max\{k\mid k|a \text{ 且 } k|b\}$$
因为要求最大公因子必须是正数，所以 $\gcd(a,b)=\gcd(|a|,b)=\gcd(a,|b|)=\gcd(|a|,|b|)$，一般来说，$\gcd(a,b)=\gcd(|a|,|b|)$。

示例：$\gcd(60,24)=\gcd(60-24,24)=12$

同样，因为零可被所有的非零整数整除，所以有 $\gcd(a,0)=|a|$。
我们说整数 $a,b$ 互素，当且仅当它们只有一个正整数公因子 1。也就是说，若 $\gcd(a,b)=1$，则 $a$、$b$ 互质。

示例：8 和 15 互质，因为 8 的正整数因子为 $1,2,4,8$，而 15 的正整数因子为 $1,3,5,15$，所以 1 是它们唯一的公因子。

### 2.2.2 求最大公因子

下面描述一个由欧几里得发明的算法，它可以简单地求出两个整数的最大公因子（见图2.2），在密码学中的描述如下。该算法的发明分为以下几点：
1. 假设这里需要求出整数 $a$ 和 $b$ 的最大公因子，即求 $d=\gcd(a,b)$；因为 $\gcd(|a|,|b|)=\gcd(a,b)$，所以这里可以假定 $a\ge b>0$。
2. 使用带余除法，$b$ 除 $a$ 可以表示为
    $$a = q_1b + r_1,\quad 0\le r_1 < b \tag{2.2}$$
3. 首先考虑 $r_1=0$ 的情况。可知 $b$ 整除 $a$，且 $a$ 和 $b$ 的公因子中不存在比 $b$ 更大的数。因此有 $d=\gcd(a,b)=b$。
4. 式(2.2)的另一种情况是 $r_1\neq0$。此时一定有 $d|r_1$。由因子的基本性质可知：存在 $d|a$ 和 $d|b$，所以一定有 $d|(a-q_1b)$，即 $d|r_1$。
5. 在应用欧几里得算法前，需要知道 $\gcd(b,r_1)$ 的值是什么。我们知道 $d$ 是 $b$ 和 $r_1$ 的公因子，现在其中 $d$ 是 $a$ 和 $b$ 的最大公因子，因此有 $d=\gcd(b,r_1)$。另外，因为 $c$ 整除 $b$ 和 $r_1$，于是 $c$ 一定整除 $a$，可见 $c$ 是 $a$ 和 $b$ 的公因子，有 $c\le d$，因此有 $d=\gcd(b,r_1)$。

![[attachments/fig_2_2_euclidean_algorithm.png]]

现在回到式(2.2)。假设 $r_1\neq0$，因为 $b>r_1$，所以可以用 $r_1$ 除 $b$，然后用带余除法得
$$b = q_2r_1 + r_2,\quad 0\le r_2 < r_1$$

如上所述，若 $r_2=0$，则 $d=r_1$；若 $r_2\neq0$，则 $d=\gcd(r_1,r_2)$。我们发现，在计算过程中，余数形成递减的一系列非负值，并且余数为零时，算法一定会终止。例如，假设在第 $n+1$ 个阶段有 $r_{n-1}$ 除以 $r_n$，结果如下：
$$
\begin{cases}
a = q_1b + r_1,\quad &0 < r_1 < b \\
b = q_2r_1 + r_2,\quad &0 < r_2 < r_1 \\
r_1 = q_3r_2 + r_3,\quad &0 < r_3 < r_2 \\
&\vdots \\
r_{n-2} = q_nr_{n-1} + r_n,\quad &0 < r_n < r_{n-1} \\
r_{n-1} = q_{n+1}r_n + 0,\quad &r_{n+1}=0
\end{cases} \tag{2.3}
$$
带余除法来求两个整数的最大公因子。该算法称为欧几里得算法。图2.3用一个简单的例子 $\gcd(710,310)$ 进行了说明。

![[attachments/fig_2_3_euclidean_algorithm_example.png]]

本质上，我们自顶向下证明了最终结果是 $\gcd(a,b)$。也可以自底向上地证明。然后，从每一个除法式子得出 $r_n$ 整除 $r_{n-2}$（因为它可以整除等式右边的两项 $q_nr_{n-1}$ 和 $r_n$）。以此类推，我们发现 $r_n$ 可以整除所有 $r_i$，最后得到 $r_n$ 整除 $a$ 和 $b$。另外，还需要证明 $r_n$ 是能够整除 $a$ 和 $b$ 的最大除数。如前所述，任何可以整除 $a$ 和 $b$ 的整数，一定可以整除 $r_1$。按照式(2.3)的顺序，可以证明 $c$ 能够整除所有 $r_i$。因此 $c$ 可以整除 $r_n$，于是 $r_n=\gcd(a,b)$。

下面通过一组较大的数字来了解这个算法的强大之处。
$d=\gcd(a,b)=\gcd(1160718174,316258250)$
完整计算过程整理为表格形式，每一步均满足 $r_{i-2}=q_ir_{i-1}+r_i$，最终余数为0时的上一轮余数即为最大公因子，本例结果为 $1078$。

## 2.3 模运算

### 2.3.1 模

若 $a$ 是一个整数，$n$ 是一个正整数，则定义 $a$ 除以 $n$ 所得的余数为 $a \bmod n$。整数 $n$ 称为模数。因此，对任意整数 $a$，总可以把式(2.1)写成
$$a = qn + r,\quad 0\le r < n;\ q=\lfloor a/n \rfloor$$

示例：$11 \bmod 7=4$；$-11 \bmod 7=3$

若 $(a \bmod n) = (b \bmod n)$，则称整数 $a$ 和 $b$ 是模 $n$ 同余的，表示为 $a \equiv b \pmod{n}$。

示例：$73\equiv4 \pmod{23}$；$21\equiv9 \pmod{10}$

注意，如果 $a\equiv0 \pmod{n}$，那么 $n|a$。

### 2.3.2 同余的性质

1. 若 $n|(a-b)$，则 $a\equiv b \pmod{n}$。
2. 若 $a\equiv b \pmod{n}$，则 $b\equiv a \pmod{n}$。
3. 若 $a\equiv b \pmod{n}$，$b\equiv c \pmod{n}$，则 $a\equiv c \pmod{n}$。

示例：$21\equiv5 \pmod{8}$，因为 $21-5=16=2\times8$；$-13\equiv3 \pmod{8}$；$81\equiv0 \pmod{27}$

### 2.3.3 模算术运算

注意，由定义可知，$r$ 的取值范围为 $0\le r\le n-1$，于是出现了这样一个问题：能否限制到这个集合上进行算术？答案是可以，这种技术称为模算术。于是 $\mathbb{Z}_n=\{0,1,\dots,n-1\}$。$\mathbb{Z}_n$ 中的每个整数代表一个剩余类。

设 $a \bmod n = r_a$，$b \bmod n = r_b$，有以下三条性质：
1. $(a+b) \bmod n = [(a \bmod n)+(b \bmod n)] \bmod n$
2. $(a-b) \bmod n = [(a \bmod n)-(b \bmod n)] \bmod n$
3. $(a\times b) \bmod n = [(a \bmod n)\times(b \bmod n)] \bmod n$

示例：
$11 \bmod 8=3;\ 15 \bmod 8=7$
$(11+15) \bmod 8=(3+7) \bmod 8=10 \bmod 8=2$
$(11-15) \bmod 8=(3-7) \bmod 8=-4 \bmod 8=4$
$(11\times15) \bmod 8=(3\times7) \bmod 8=21 \bmod 8=5$

指数运算和普通算术一样，可以通过反复的乘法实现。

模8加法、乘法表完整列出，可直观看到模运算封闭性。

![[attachments/table_2_2_mod_8_operations.png]]

### 2.3.4 模运算的性质

$\mathbb{Z}_n$ 中整数模运算的性质汇总表：

| 性质 | 表达式 |
| --- | --- |
| 交换律 | $(w+x) \bmod n = (x+w) \bmod n$<br>$(w\times x) \bmod n = (x\times w) \bmod n$ |
| 结合律 | $[(w+x)+y] \bmod n = [w+(x+y)] \bmod n$<br>$[(w\times x)\times y] \bmod n = [w\times(x\times y)] \bmod n$ |
| 分配律 | $[w\times(x+y)] \bmod n = [(w\times x)+(w\times y)] \bmod n$ |
| 单位元 | $(0+w) \bmod n = w \bmod n$<br>$(1\times w) \bmod n = w \bmod n$ |
| 加法逆元 | 对任意 $w$，存在 $z$ 使得 $(w+z)\equiv0 \pmod{n}$ |

然而，下面的说法只有在附加条件时才成立：
$$ax \equiv ay \pmod{n} \implies x\equiv y \pmod{n} \tag{2.5}$$
其中重要的概念是这样定义的：若 $x$ 与模数 $n$ 互素，则 $a$ 的乘法逆元是唯一的。将 $a$ 的乘法逆元加到式(2.5)的两边可得：
$$(a^{-1}ax) \equiv (a^{-1}ay) \pmod{n} \implies x\equiv y \pmod{n}$$

示例：$6\times3=18\equiv2 \pmod{8}$，$6\times7=42\equiv2 \pmod{8}$，$3\not\equiv7 \pmod{8}$。原因是6和8不互素，无乘法逆元。

一般来说，只有当一个整数与模数 $n$ 互素时，才会在 $\mathbb{Z}_n$ 中存在乘法逆元。

### 2.3.5 欧几里得算法回顾

欧几里得算法基于下面的定理：对任意整数 $a,b$，且 $a\ge b\ge0$，有
$$\gcd(a,b)=\gcd(b,a \bmod b) \tag{2.6}$$

示例：$\gcd(55,22)=\gcd(22,55 \bmod 22)=\gcd(22,11)=11$
$\gcd(18,12)=\gcd(12,6)=\gcd(6,0)=6$
$\gcd(1,10)=\gcd(10,1)=\gcd(1,0)=1$

递归形式欧几里得算法伪代码：
```
Euclid(a,b)
    if b=0 then return a;
    else return Euclid(b, a mod b);
```

### 2.3.6 扩展欧几里得算法

下面介绍扩展欧几里得算法，它在有限域的计算及RSA等密码算法非常重要。对于给定的整数 $a$ 和 $b$，扩展欧几里得算法不仅可以算出 $\gcd(a,b)$，而且可以得到两个整数 $x,y$ 使满足方程：
$$ax + by = \gcd(a,b) \tag{2.7}$$

推导过程：
沿用欧几里得余数序列 $r_{i-2}=q_ir_{i-1}+r_i$，变形得 $r_i = r_{i-2}-q_ir_{i-1}$。
每一步余数都可表示为 $r_i = ax_i + by_i$，迭代更新系数 $x,y$，最终当余数 $r_n=\gcd(a,b)$ 时，得到满足 $ax+by=d$ 的 $x,y$。

完整迭代计算表格，包含每一步余数、商、系数 $x,y$ 更新规则。

实例：$\gcd(1759,550)$，计算得 $d=1,\ x=-111,\ y=355$，验证：$1759\times(-111)+550\times355=1$。

## 2.4 素数

数论的核心是素数，实际上所有关于数论的书都是围绕这一主题来写的。
整数 $p>1$ 是素数，当且仅当它只有因子 1 和 $p$。除1和素数外的所有数都是合数。换句话说，合数是那些至少能构成两个数的积的数。素数在数论和本章讨论的各种方法中起着重要作用。表2.5列出了2000以内的素数。

**算术基本定理**：任意整数 $a>1$ 都可以唯一地因式分解为
$$a = p_1^{a_1}p_2^{a_2}\dots p_k^{a_k} \tag{2.9}$$
式中，$p_1<p_2<\dots<p_k$ 均是素数，且所有的 $a_i$ 都是正整数。

示例：$91=7\times13$；$3600=2^4\times3^2\times5^2$

另一种表示：设 $P$ 是所有素数的集合，则任意正整数 $a$ 可以唯一表示为
$$a=\prod_{p\in P}p^{a_p},\quad a_p\ge0$$
绝大多数指数 $a_p$ 为0，表示该素数不在分解式中。

整数相乘等价于对应素数指数相加：
若 $a=\prod p^{a_p},\ b=\prod p^{b_p}$，定义 $k=ab$，则 $k=\prod p^{a_p+b_p}$。

利用素因子分解求最大公因子：
设 $c=\gcd(a,b)$，则 $c=\prod p^{\min(a_p,b_p)}$。
示例：$300=2^2\times3^1\times5^2$；$18=2^1\times3^2$；$\gcd(300,18)=2^1\times3^1\times5^0=6$。

## 2.5 费马定理和欧拉定理

费马定理和欧拉定理在公钥密码学中有重要的地位。

### 2.5.1 费马定理

**费马小定理**：若 $p$ 是素数，$a$ 是正整数且不能被 $p$ 整除，则
$$a^{p-1} \equiv 1 \pmod{p} \tag{2.10}$$

另一种等价形式：若 $p$ 是素数，$a$ 是任意正整数，则
$$a^p \equiv a \pmod{p} \tag{2.11}$$

示例：$p=7,a=3$
$3^6=729\equiv1 \pmod{7}$；$3^7=2187\equiv3 \pmod{7}$

### 2.5.2 欧拉函数

在给出欧拉定理之前，我们需要引入数论中的一个非常重要的概念：欧拉函数 $\phi(n)$，它指小于 $n$ 且与 $n$ 互素的正整数的个数。

示例：$\phi(37)=36$（37是素数，1~36全部与37互素）；$\phi(6)=2$（1,5与6互素）。

欧拉函数性质：
1. 若 $p$ 为素数，则 $\phi(p)=p-1$。
2. 若 $p$ 为素数，$a\ge1$，则 $\phi(p^a)=p^a-p^{a-1}=p^{a-1}(p-1)$。
3. 若 $m,n$ 互素，则 $\phi(mn)=\phi(m)\phi(n)$。

任意 $n$ 标准素分解 $n=p_1^{k_1}p_2^{k_2}\dots p_r^{k_r}$，则：
$$\phi(n)=n\prod_{i=1}^r\left(1-\frac{1}{p_i}\right)$$

示例：$\phi(21)=\phi(3\times7)=\phi(3)\phi(7)=2\times6=12$。

![[attachments/table_2_6_euler_totient_values.png]]

### 2.5.3 欧拉定理

对任意互素的 $a$ 和 $n$，有
$$a^{\phi(n)} \equiv 1 \pmod{n} \tag{2.12}$$

推论：$a$ 和 $n$ 互素，则 $a$ 的乘法逆元为 $a^{\phi(n)-1} \bmod n$。

示例：$a=3,n=10,\phi(10)=4$，$3^4=81\equiv1 \pmod{10}$。

## 2.6 素性测试

目前还没有简单高效的方法来分解一个非常大的整数。因此我们必须确定一个给定的大数是否是素数。本节介绍常用素性测试算法：Miller-Rabin概率素性测试。

### 2.6.1 Miller-Rabin 算法

基于二次剩余、费马小定理反向推导，合数会存在"证人"使其不满足同余式，素数一定通过测试。
算法流程：
1. 对奇数 $n>2$，将 $n-1$ 分解为 $n-1=2^kq$，$q$ 奇数。
2. 随机选取 $a\in(1,n-1)$，计算 $x=a^q \bmod n$。
3. 若 $x=1$ 或 $x=n-1$，本轮通过；否则循环平方 $k-1$ 次。
4. 若中途出现 $x=n-1$，通过；否则判定 $n$ 为合数。

重复多轮独立选取不同 $a$ 测试，可大幅降低误判概率。
该算法是**概率算法**：通过测试仅代表大概率为素数，无法100%确认；未通过则一定是合数。

### 2.6.2 一个确定性的素性判定算法

在2002年以前，没有高效的确定性素性测试方法。Miller-Rabin测试被广泛接受，因为它可以以极低的错误概率快速执行。2002年，Agrawal、Kayal和Saxena提出了一种相对简单的确定性素性测试算法（AKS算法），证明了可以在多项式时间内测试素性。然而，AKS算法比Miller-Rabin慢，目前还没有取代Miller-Rabin算法。

### 2.6.3 素数分布

值得注意的是，在利用Miller-Rabin测试或任何其他素性测试算法找到一个素数之前，我们需要知道要选多少个奇数才能找到一个素数。数论中的一个著名结果，即素数定理（prime number theorem）称：在 $n$ 附近，平均每 $\ln n$ 个整数中有一个素数。由于偶数都不是大于2的素数，因此只需测试奇数，平均需要测试 $0.5\ln n$ 个整数。例如，在 $2^{200}$ 附近找一个素数，平均需要约 $0.5\ln(2^{200})\approx69$ 次测试。

当然，这个结果只是平均值。在数轴上，素数的分布是不均匀的：某些区域连续的奇数都是素数，而另一些区域存在很长的合数间隙。例如，$1001!+2,1001!+3,\dots,1001!+1001$ 这1000个连续整数都是合数。

## 2.7 中国剩余定理

中国剩余定理是数论中最有用的定理之一。CRT说明，某个范围内的整数可通过它的一组余数来重构，这组余数是对该整数用一组两两互素的整数取模得到的。

### 定理表述

设 $m_1,m_2,\dots,m_k$ 两两互素，记 $M=\prod_{i=1}^k m_i$。
$\mathbb{Z}_M$ 中任意整数 $A$ 对应唯一元组 $(a_1,a_2,\dots,a_k)$，满足 $a_i=A \bmod m_i$。

1. 对任意 $A\in\mathbb{Z}_M$，存在唯一元组 $(a_1,\dots,a_k)$；反之，给定一组余数，存在唯一 $A\in[0,M)$。
2. $\mathbb{Z}_M$ 上的加减乘运算等价于各分量独立模 $m_i$ 运算。

### 求解公式

记 $M_i = M/m_i$，$M_i^{-1}$ 为 $M_i$ 在模 $m_i$ 下的乘法逆元：
$$c_i = M_i \times (M_i^{-1} \bmod m_i) \tag{2.16}$$
$$A = \left(\sum_{i=1}^k a_ic_i\right) \bmod M \tag{2.17}$$

### 实例

求解 $x\equiv3 \pmod{7},\ x\equiv4 \pmod{13}$
$m_1=7,m_2=13,M=91,\ M_1=13,M_2=7$
$13^{-1}\bmod7=6,\ 7^{-1}\bmod13=2$
$c_1=13\times6=78,\ c_2=7\times2=14$
$A=(3\times78+4\times14) \bmod91=290 \bmod91=17$
验证：$17\bmod7=3,\ 17\bmod13=4$。

### 密码学用途

大数模运算可拆分为多个小模数分别计算，最后用CRT合并结果，大幅降低计算开销，广泛用于RSA解密/签名优化。

## 2.8 离散对数

离散对数是包括Diffie-Hellman密钥交换算法和数字签名算法（DSA）在内的许多公钥算法的基础。

### 2.8.1 模 $n$ 的整数幂

由欧拉定理，若 $a,n$ 互素，则 $a^{\phi(n)}\equiv1 \pmod{n}$。
满足 $a^m\equiv1 \pmod{n}$ 的最小正整数 $m$ 称为 $a$ 模 $n$ 的**阶/周期**。

若 $a$ 的阶等于 $\phi(n)$，称 $a$ 是模 $n$ 的**本原根**。
只有 $n=2,4,p^\alpha,2p^\alpha$（$p$ 为奇素数）存在本原根。

示例：模19，2是本原根，$2^k \bmod19$ 遍历 $1\sim18$ 所有非零剩余。

![[attachments/table_2_7_integer_powers_mod_19.png]]

### 2.8.2 模算术对数

设 $g$ 是模 $p$ 的本原根，对任意整数 $b$，存在唯一整数 $x\ (0\le x\le p-1)$ 满足：
$$g^x \equiv b \pmod{p}$$
称 $x$ 为以 $g$ 为底、模 $p$ 下 $b$ 的**离散对数**，记作 $\log_g(b) \pmod{\phi(p)}$。

离散对数满足普通对数的运算性质：
$$\log_g(ab) \equiv [\log_g(a)+\log_g(b)] \pmod{\phi(p)}$$
$$\log_g(a^c) \equiv [c\times\log_g(a)] \pmod{\phi(p)}$$

![[attachments/table_2_8_discrete_logarithms_mod_19.png]]

### 2.8.3 离散对数的计算

已知 $g,x,p$ 求 $y=g^x \bmod p$ 是快速幂，计算简单；
已知 $g,y,p$ 求 $x$（求解离散对数）是计算困难问题，无多项式高效算法，是DH、DSA等密码体系的安全根基。

## 附录 2A mod 的含义

本书中 `mod` 有两种用途：
1. **二元运算符**：$a \bmod n$，表示 $a$ 除以 $n$ 的余数，$0\le r<n$。
2. **同余关系符号**：$a\equiv b \pmod{n}$，表示 $a,b$ 模 $n$ 余数相等，二者属于同一剩余类。

剩余类：模 $n$ 将全体整数划分为 $n$ 个互不相交集合 $\{0,1,\dots,n-1\}$，每个集合称为一个模 $n$ 剩余类。
$a\equiv b \pmod{n} \iff n\mid(a-b)$。
