## 18.1 无线安全

### 风险因素

| 信道 | 移动性 | 资源 | 易接近性 |
| --- | --- | --- | --- |
| 广播、窃听、干扰、注入 | 设备和边界动态变化 | 有限计算/内存易受DoS和恶意软件 | 无人区域设备易遭物理攻击 |

![[attachments/fig_18_1_pdf389.png]]

*图18.1：客户端、接入点、无线介质构成三类攻击点。*

### 18.1.1 无线网络威胁

- 意外关联；
- 恶意关联/伪装AP；
- 无中央控制的自组网络；
- 蓝牙等非传统网络；
- MAC地址欺骗；
- 中间人攻击；
- 无线DoS；
- 注入路由、管理和重置命令。

### 18.1.2 无线安全措施

| 层次 | 措施 |
| --- | --- |
| 传输 | 信号隐藏/屏蔽、控制功率、加密、认证、频谱调查 |
| 接入点 | IEEE 802.1X基于端口认证和接入控制 |
| 网络与端点 | 改默认标识/口令、防火墙、反病毒、加密、有限MAC白名单 |

> [!WARNING] 易错点
> 隐藏SSID和MAC白名单不提供可靠密码学认证；MAC可观察和伪造。

## 18.2 移动设备安全

### 环境变化

大量新设备、云应用、静态边界消失和外部商务接入，使“受控PC+内部网络+数据中心”模型失效。

### 18.2.1 安全威胁

| 因素 | 威胁 |
| --- | --- |
| 物理控制不足 | 盗窃、篡改、数据与凭证泄露 |
| 不可信设备 | BYOD未加密、越狱、绕过限制 |
| 不可信网络 | 窃听和中间人 |
| 未知应用 | 恶意软件 |
| 系统交互 | 自动同步至不安全设备/云 |
| 不可信内容 | 恶意二维码、URL |
| 位置服务 | 设备和人员位置泄露 |

### 18.2.2 移动设备安全策略

![[attachments/fig_18_2_pdf393.png]]

*图18.2：设备、数据流和屏障安全。*

| 类别 | 关键控制 |
| --- | --- |
| 设备安全 | 锁屏、PIN、更新、反病毒、远程清除、加密、应用白名单/沙箱、同步限制 |
| 数据流安全 | SSL/VPN加密；强认证；设备和用户双层认证 |
| 屏障安全 | 专用防火墙、IDS/IPS、限制移动设备访问范围 |

## 18.3 IEEE 802.11无线局域网概述

### 关键术语

| 术语 | 定义 |
| --- | --- |
| AP | 通过无线介质为关联STA提供DS访问 |
| BSS | 单个协调功能控制的STA集合 |
| IBSS | STA无AP直接通信的独立BSS |
| DS | 互连BSS并集成LAN的系统 |
| ESS | 多个互连BSS及集成LAN，对LLC呈单一BSS |
| MSDU | MAC用户间传输的信息单元 |
| MPDU | 对等MAC实体经物理层交换的数据单元 |
| STA | 符合802.11 MAC和物理层的设备 |

### 18.3.1 Wi-Fi联盟

Wi-Fi联盟负责产品互操作认证；教材中的WPA2整合IEEE 802.11i安全功能。IEEE制定标准，联盟认证实现。

### 18.3.2 IEEE 802协议架构

![[attachments/fig_18_3_pdf394.png]]

*图18.3：物理层、MAC层、LLC层。*

| 层 | 功能 |
| --- | --- |
| 物理层 | 编码、位传输、介质、频带和天线 |
| MAC层 | 介质访问、帧封装/拆封、地址、CRC检错 |
| LLC层 | 跟踪成功帧并重发失败帧 |

![[attachments/fig_18_4_pdf395.png]]

*图18.4：MPDU含控制、目的/源MAC、MSDU和CRC。*

**CRC**是公开线性检错码，不是带密钥的完整性认证。

### 18.3.3 网络构成和架构模型

![[attachments/fig_18_5_pdf396.png]]

*图18.5：BSS经AP和DS组成ESS；IBSS不使用AP。*

- 基础设施BSS内STA之间也经AP中继；
- DS可以是交换机、有线网络或无线网络；
- ESS对LLC表现为一个逻辑LAN。

### 18.3.4 IEEE 802.11服务

#### 九项服务

| 类别 | 服务 |
| --- | --- |
| DS提供、支持发送 | 关联、重新关联、解除关联、分发、整合 |
| STA提供 | MSDU发送、认证、解除认证、隐私 |

#### 移动性

| 类型 | 说明 |
| --- | --- |
| 无过渡 | 固定或在同一BSS直接通信范围内移动 |
| BSS过渡 | 同一ESS内换BSS，重新关联更新位置 |
| ESS过渡 | 进入不同ESS，上层连接不保证连续 |

关联使DS知道STA当前对应AP，分发服务据此寻址。

## 18.4 IEEE 802.11i无线局域网安全

### 18.4.1 IEEE 802.11i服务

认证、访问控制、隐私和信息完整性。

![[attachments/fig_18_6_pdf398.png]]

*图18.6：认证/访问控制协议与TKIP/CCMP数据保护。*

### 18.4.2 IEEE 802.11i操作阶段

![[attachments/fig_18_7_pdf399.png]]

*图18.7：发现、认证、密钥、受保护传输、终止。*

| 阶段 | 内容 |
| --- | --- |
| 发现 | 找AP、协商密码和AKM、关联 |
| 认证 | STA-AS相互认证，AP转发控制流量 |
| 密钥生成/分发 | AP-STA生成并安装密钥 |
| 受保护传输 | TKIP/CCMP保护STA-AP MPDU |
| 终止 | 拆除安全连接并复位 |

802.11i只保护STA-AP无线链路，不保护DS中的端到端路径。

### 18.4.3 发现阶段

![[attachments/fig_18_8_pdf400.png]]

*图18.8：Beacon/Probe发现、开放系统认证、关联、EAP认证。*

#### 协商项目

- 单播保密/完整性：WEP、TKIP、CCMP或厂商方法；
- 组播/广播套件由AP控制；
- AKM：802.1X、PSK或厂商方法。

开放系统认证只交换标识以兼容状态机，不提供安全。无共同安全能力则关联失败；关联后受控端口仍阻塞。

### 18.4.4 认证阶段

| 角色 | 实体 |
| --- | --- |
| 请求者 | STA |
| 认证器 | AP |
| 认证服务器 | AS/AAA服务器 |

不受控端口传递EAP控制消息，受控端口传用户数据。STA-AP常用EAPOL，AP-AS常用RADIUS。成功后产生MSK/AAA密钥，但四次握手安装临时密钥前，受控端口仍阻塞。

### 18.4.5 [[Course Notes/密码学 (Cipher)/Key Management and the Public-Key Revolution/Key Management and the Public-Key Revolution|密钥管理]]阶段

![[attachments/fig_18_9_pdf402.png]]

*图18.9：成对密钥树与组密钥树。*

#### 成对密钥

| 密钥 | 作用 |
| --- | --- |
| MSK/AAA密钥 | 802.1X认证产生的根密钥，派生PMK |
| PSK | 预共享环境的根密钥，直接作为PMK |
| PMK | 派生PTK |
| PTK | 组合密钥，含KCK、KEK、TK及TKIP MIC密钥 |
| KCK | 4次握手EAPOL消息完整性与PMK持有证明 |
| KEK | 保护GTK和其他密钥内容保密性 |
| TK | 单播用户数据保密性与完整性 |

#### 组密钥

GMK由AP生成；GTK由GMK和其他输入派生，保护多播/广播。GTK通过每个STA已有成对密钥安全分发，成员离开时应更换。

![[attachments/fig_18_10_pdf404.png]]

*图18.10：四次握手和两次组密钥握手。*

#### 四次握手

1. AP发送Anonce；
2. STA生成Snonce，派生PTK，以KCK生成MIC；
3. AP派生相同PTK并发送带MIC的确认/安装消息；
4. STA发送带MIC的确认。

目的：确认PMK持有、验证密码套件、生成并安装新PTK。PMK/PTK不在空中直接发送。

#### 组密钥握手

AP以KEK包装GTK并附MIC；STA收到后以MIC确认。

### 18.4.6 安全数据传输阶段

| 属性 | TKIP | CCMP |
| --- | --- | --- |
| 适用 | 软件升级旧WEP设备 | 新[AES](<../../../../../Course Notes/密码学 (Cipher)/Practical Constructions of Symmetric-Key Primitive/Practical Constructions of Symmetric-Key Primitives (I).md>)硬件 |
| 保密 | RC4及逐帧动态密钥 | AES-[CTR](<../../../../../Course Notes/密码学 (Cipher)/Private-Key Encryption (VI)/Private-Key Encryption (VI).md>) |
| 完整性 | Michael 64位MIC | [[CBC]]-MAC |
| 重放 | TSC | 48位包号 |
| 密钥 | 256位TK组合使用 | 128位AES密钥 |

### 18.4.7 IEEE 802.11i伪随机函数

$$
PRF(K,A,B,Len)
$$

K为密钥，A为用途标签，B为上下文数据，Len为所需位数。

$$
PTK=PRF(PMK,"Pairwise\ key\ expansion",\min(AA,SA)\parallel\max(AA,SA)\parallel\min(ANonce,SNonce)\parallel\max(ANonce,SNonce),384)
$$

$$
GTK=PRF(GMK,"Group\ key\ expansion",MAC\parallel Gnonce,256)
$$

## 教材内容与补充理解

> [!NOTE] 教材结论
> 802.11i把安全拆为能力发现、身份认证、密钥管理和受保护传输；四次握手从共同PMK派生并确认PTK；TKIP和CCMP保护STA-AP帧。

> [!INFO] 补充理解
> 可把地址、nonce和用途标签视为密钥的“上下文边界”：同一PMK在不同设备对、不同握手和不同用途下导出不同结果。这一解释用于帮助理解PRF输入。
