# 第23章 物联网安全 — 章末学习目标自检

---

## 1. 能否解释物联网中"物"的范围、四代终端演化，以及低带宽设备与视频设备的差别？

**物联网（IoT）** 是从大型家电到微型传感器等智能设备的扩展互连，把通信能力嵌入日常用品和工业设备，实现人与物、物与物通信，通过采集数据、改变环境和控制设备管理工厂、城市等更大系统。物联网主要由**深度嵌入式设备**驱动。

**四代终端演化**：

| 阶段 | 典型设备及使用者 | 连接特点 |
| --- | --- | --- |
| 信息技术（IT） | 企业 IT 人员采购的计算机、服务器、路由器、防火墙 | 主要有线 |
| 操作技术（OT） | OT 人员采购的医疗器械、SCADA、过程控制等带嵌入式 IT 的机器 | 主要有线 |
| 个人技术 | 消费者/员工购买的智能手机、平板、电子书 | 无线，通常支持多种无线方式 |
| 传感器或执行器技术 | 单用途设备，构成大型系统一部分 | 通常采用单一无线连接 |

第四代以海量嵌入式设备为特征，即物联网。其安全影响不仅是数据被窃取或篡改，还可能通过执行器**直接改变物理环境**。

**带宽差别**：许多设备只需低带宽、低频次采集交换数据；但视频监控摄像机等需要高带宽流媒体，不能把所有物联网设备一概视为低流量设备。

## 2. 能否说明传感器、执行器、微控制器、收发机和电源的作用，并区分 RFID 识别与传感器测量？

| 组件 | 功能 |
| --- | --- |
| **传感器** | 测量物理、化学或生物参数，将观察结果转换为模拟电压或数字信号，为微控制器提供输入 |
| **执行器** | 接收控制信号并改变环境参数，把电子指令转换为对环境的作用 |
| **微控制器** | 提供深度嵌入的处理与控制能力，构成设备的"智能"，联系感知、控制和通信 |
| **收发机** | 发送和接收数据，通常通过 Wi-Fi、ZigBee 等无线方式连接设备或网关 |
| **电源** | 为各组件供能（通常是电池），电量限制影响设备运行和安全机制设计 |

**RFID 与传感器的区别**：RFID 系统由标签和阅读器组成，标签保存可识别物品的信息，阅读器在工作范围内读取（有时可重写），支持的是**物品识别**；传感器测量的是**环境参数**（温度、压力等），二者功能不同。

## 3. 能否描述边缘、雾、核心和云各自的职责，列出雾计算的五类处理并比较云与雾？

**分层架构**：

| 层面 | 职责 |
| --- | --- |
| **边缘** | 传感器和执行器采集数据、相互通信并作用于环境；网关执行协议转换和基本数据聚合 |
| **雾** | 在接近数据源处处理大量数据，把数据流转化为适合存储和进一步分析的信息 |
| **核心** | 以高性能路由器、大容量链路和冗余连接互联分散的雾网络，连接其他网络、数据库或私有云 |
| **云** | 存储和处理聚合数据，托管设备管理、交互及数据分析应用 |

雾计算动机：减少把所有原始数据送到中心处理的开销，减轻网络容量压力，满足低延迟要求，应对安全隐私挑战。

**雾计算五类处理**：
1. **估计**：按标准判断数据是否需要送往更高层；
2. **格式化**：转换为适合统一处理的格式；
3. **扩展/解码**：处理加密数据及数据源等附加信息；
4. **净化/减少**：减少、汇总数据，降低流量和后续处理负担；
5. **评估**：判断是否达到阈值或触发警报，必要时改变数据目的地。

**云与雾比较**：

| 比较项 | 云计算 | 雾计算 |
| --- | --- | --- |
| 资源位置 | 中心化设施 | 靠近设备和传感器的边缘设施 |
| 延迟 | 相对较高 | 相对较低 |
| 接入 | 固定或无线 | 主要无线，支持移动性 |
| 控制 | 集中/分层，经核心访问 | 分布式/分层，边缘或手持设备访问 |
| 数据规模 | 面向较少分散用户，海量集中资源 | 面向海量设备，数据各处产生使用 |
| 可用性 | 集中设施较高可用 | 节点可用性高度不稳定，依赖高冗余 |

## 4. 能否定义漏洞修补，解释物联网供应链和设备限制导致的修补困难，并说明测试、部署与维护要求？

**漏洞修补**是通过更新固件或软件、部署安全补丁，修复已知安全缺陷，使设备不再容易被相应漏洞利用的过程。

**修补困难的根源**：
- **供应链割裂**：芯片制造商追求快速低成本交付，设备制造商按价格和功能选芯片，对附带固件和软件改动很少；
- 最终用户可能既没有更新手段，也不知道何时、如何修补；
- 资源受限、低成本和快速部署进一步加重问题；
- 未修补的传感器可能被用于注入虚假数据，未修补的执行器可能让攻击者操纵机器操作。

**测试、部署与维护要求**：
1. 在现场条件下测试安全补丁，随后尽可能快地部署；
2. 网关应支持固件和软件更新，以及自诊断、自修复和远程维护；
3. 同时禁用未用端口和服务，限制用户角色权限，持续审计和监控；技术可行时使用杀毒软件和文件完整性检查。

修补是设备生命周期中的持续工作，需与安全配置、运行监控和事故恢复共同实施。

## 5. 能否概括物联网生态系统的安全挑战、七项安全目标、防篡改与检测方法、网关职责和实际保护边界？

**生态系统安全挑战**：规模与复杂性（攻击面大、风险评估困难）；资源与成本（内存、算力、电源有限，低价竞争压缩安全）；部署与物理影响（快速进入关键基础设施，网络攻击可影响物理运行）；标准与集成碎片化；专业人员不足、开发重功能轻安全；固件难修补、供应链责任不清。

**七项安全目标**：

| 目标 | 措施 |
| --- | --- |
| 限制逻辑接入 | 单向网关、防火墙、多层网络；企业与物联网独立认证；关键通信置于最安全层 |
| 限制物理访问 | 锁、读卡器、看守等物理访问控制 |
| 防止组件被编程入侵 | 及时补丁、禁用闲置端口服务、限制角色权限、跟踪审计 |
| 防止未授权修改数据 | 保护传输中（尤其跨边界）和静止数据 |
| 检测事件和事故 | 尽早发现攻击、组件失效、服务不可用、资源耗尽，打断攻击链 |
| 不利条件下保持功能 | 关键组件冗余，避免故障扩散；必要时从全自动降级到人工或手动 |
| 事故后恢复 | 预先建立事故响应计划，事故后快速恢复 |

**防篡改与篡改检测**：防篡改提供被动保护，篡改检测使系统察觉非法物理访问，对部署在安全场所以外的边缘和雾节点尤其重要。手段包括：坚硬外壳/安全螺栓（提高侵入难度）；特殊封条胶带（留下可见证据）；磁性开关/压力触点（开关检测开盖）；温度/辐射/电压传感器（检测异常环境）；柔性电路/电阻丝/光纤封装（电路检测损坏）。

**网关职责（Y.2067）**：标识每次设备访问；支持单向或相互设备认证并与应用相互认证；保护设备和网关内静止数据及两段传输数据；保护隐私；支持自诊断、自修复和远程维护；支持固件软件更新；支持本地/远程、自动/手动及基于策略的动态配置。

**实际保护边界（重要）**：网关到中央平台的 TLS/IPsec 安全连接，**不会自动保护设备到网关这一段，也不会自动保护设备内的存储数据**。受限设备缺少加密能力时，必须明确实际保护范围。访问控制可采用 RBAC：权限分配给角色，再按职责把用户分配给角色。

## 6. 能否说明 MiniSec 的六项要求、U/B 两种模式的防重放机制，以及 OCB 的时变值、偏移、末块处理和标签验证？

TinyOS 面向内存、处理时间、实时响应和功耗受限的小型嵌入式系统（典型约 48 KB 代码、10 KB RAM）。**MiniSec** 是其开源链路级安全模块，以较少内存和较低能耗提供保密性、认证和重放保护，采用 Skipjack 分组密码和 OCB 模式（教材指出 80 位密钥通常不安全，今后应采用较新的轻量级密码）。

**六项设计要求**：数据认证（验证来源合法且未改）、保密性、重放保护、弱新鲜度（不依赖本地参考时间点也能对消息局部排序）、低能量开销（只用对称密码、减少通信）、容忍消息丢失。

**两种模式的防重放**：

| 比较项 | MiniSec-U（单播） | MiniSec-B（广播） |
| --- | --- | --- |
| 机制 | 接收端为每个发送方维护本地严格递增计数器，拒绝相同或更小值的包；丢包失步时重同步 | 时间划分为长度 $t$ 的时间段 $E_i$，结合**布隆过滤器**检查段内重复 |
| 时变值 | 计数器 | 发送方标识、时间段和共享计数器组合 $\mathrm{nodeID}.E_i.C_{ab}$（点为字符串组合） |
| 代价 | 多发送方增加接收端计数器状态 | 无须逐发送方保存状态，适合大型网络 |

**OCB（偏移码本模式）**：一次消息处理同时生成密文和认证标签，允许分组并行。设分组数 $m = \lceil \operatorname{len}(M)/n \rceil$，完整分组：

$$C[i] = E_K(M[i] \oplus Z[i]) \oplus Z[i], \qquad 1 \le i < m$$

与 ECB 相同明文块产生相同密文块不同，OCB 在加密前后加入随位置和消息变化的偏移量 $Z[i]$。

**时变值与偏移生成**：时变值 $N$ 不需保密，但**同一密钥下每条消息必须使用不同的 $N$**：

$$L = E_K(0^n), \quad R = E_K(N \oplus L), \quad L(i) = 2 \cdot L(i-1)$$

$$Z[1] = L \oplus R, \quad Z[i] = Z[i-1] \oplus L(\operatorname{ntz}(i))$$

乘法在 $\mathrm{GF}(2^n)$ 中进行，$\operatorname{ntz}(i)$ 为 $i$ 二进制末尾连续零的个数。

**末块处理**（末块位长 $\ell$，可不足 $n$ 位）：

$$X[m] = [\ell]_n \oplus L(-1) \oplus Z[m], \quad Y[m] = E_K(X[m]), \quad C[m] = M[m] \oplus \operatorname{MSB}_{\ell}(Y[m])$$

密文与明文等长。校验和与认证标签：

$$\mathrm{Checksum} = \left(\bigoplus_{i=1}^{m-1} M[i]\right) \oplus Y[m] \oplus (C[m] \parallel 0^{n-\ell})$$

$$\mathrm{Tag} = \operatorname{MSB}_{\tau}\bigl(E_K(\mathrm{Checksum} \oplus Z[m])\bigr)$$

接收方解密并重算校验和与标签，与收到的标签比较，通过后接受明文；新鲜度和重放判断另由计数器或时间段机制完成。
