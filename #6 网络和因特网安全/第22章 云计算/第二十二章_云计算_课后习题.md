# 第22章 云计算 - 课后习题

## 习题

### 22.1 云计算定义

#### 题目原文

定义云计算。

#### 教材依据

22.1.1；NIST SP 800-145定义。

#### 解题思路

保留共享资源池、网络访问、按需、自助、快速配置/释放和低管理交互等限定。

#### 参考解答

云计算是一种支持对共享的可配置计算资源池（网络、服务器、存储、应用和服务等）进行无所不在、方便、按需的网络访问的模型，并能以最小管理开销或与服务提供者的交互快速配置和释放这些资源。该模型由广泛网络接入、快速可伸缩、计量服务、按需自助服务和资源池化五个基本特征，以及三个服务模型和四个部署模型构成。

#### 重点讲解

定义的关键不是“资源在远程”，而是共享池、按需自助、弹性、计量和标准网络接入共同成立。

#### 易错点提示

不要把普通远程托管或单台VPS直接等同于完整云计算模型。

#### 核验状态

已按22.1.1原文定义核验。

### 22.2 三个云服务模型

#### 题目原文

列出并简要定义三个云服务模型。

#### 教材依据

22.1.2；图22.2。

#### 解题思路

从CSP提供的抽象层和CSC控制范围比较。

#### 参考解答

| 模型 | 定义 |
| --- | --- |
| SaaS | CSP提供运行在云基础设施上的完整应用，用户通过浏览器等接口使用；CSP负责应用安装、维护、升级和底层栈 |
| PaaS | CSP提供运行环境、中间件、开发工具等平台，用户部署和管理自己创建/获得的应用及数据 |
| IaaS | CSP提供处理、存储、网络和虚拟机等基础资源，用户控制操作系统、部署的应用和数据，并可能控制部分主机网络组件 |

#### 重点讲解

从SaaS到IaaS，用户控制增加，但自行配置、补丁和安全责任也增加。

#### 易错点提示

SaaS/PaaS/IaaS是服务模型；公有云/私有云等是部署模型，不能一一对应。

#### 核验状态

已按22.1.2和图22.2核验。

### 22.3 云计算参考架构

#### 题目原文

什么是云计算参考架构？

#### 教材依据

22.1.4；图22.5～22.6。

#### 解题思路

先定义参考架构的用途和非目标，再列五个角色。

#### 参考解答

云计算参考架构是描述云计算需求、结构和操作的通用高层概念模型。NIST参考架构关注云服务需要“什么”，而不是某个产品“如何”设计和实现；它为理解、比较、分类云服务，以及分析安全性、互操作性和可移植性标准提供公共语言。架构定义云服务消费者、云服务提供商、云审计者、云经销商和云承载商五个主要角色及其职责和交互。

#### 重点讲解

参考架构不是可直接部署的具体系统架构，而是建立系统特定架构时使用的共同框架。

#### 易错点提示

云经销商负责中介/聚合/套利服务；云承载商负责连接和传输，两者职责不同。

#### 核验状态

已按22.1.4核验。

### 22.4 云的主要安全威胁

#### 题目原文

介绍针对云的一些主要安全威胁。

#### 教材依据

22.2；22.3.1～22.3.13。

#### 解题思路

按教材列出的12类威胁逐项简述，并用STRIDE理解其安全目标。

#### 参考解答

| 威胁 | 主要风险与对策 |
| --- | --- |
| 数据泄露 | 多租户或错误访问使敏感数据暴露；保护静止/传输/使用中数据，客户端持钥加密 |
| 弱IAM | 账号生命周期、认证和授权薄弱；强认证、身份联邦、最小权限和审计 |
| 不安全API | 管理接口被绕过或滥用；强认证/授权、加密传输、监控和依赖链审查 |
| 系统漏洞 | 共享平台缺陷扩大影响；扫描、补丁、风险管理和培训 |
| 账号劫持 | 凭证被盗后读写云资源；禁共享凭证、双因素和异常监控 |
| 恶意内部人员 | CSP高权限角色滥用；供应链评估、合同约束、透明审计和报告流程 |
| APT | 长期隐蔽窃取高价值数据；威胁情报、分层检测、缩短发现和响应时间 |
| 数据丢失 | 数据/备份被误删或恶意删除；定期备份、地理冗余和恢复验证 |
| 尽职调查不足 | 迁移/合同风险未识别；核实基础设施、认证、控制和持续尽职 |
| 滥用云服务 | 低门槛资源用于垃圾邮件、恶意代码和DoS；注册验证、欺诈/流量/黑名单监控 |
| 拒绝服务 | 公共接口和共享资源不可用；威胁情报、自动保护、容量和恢复 |
| 共享技术漏洞 | CPU/GPU/虚拟化隔离不足导致跨租户影响；安全配置、强管理访问、补丁、扫描和审计 |

STRIDE从身份欺骗、篡改、抵赖、信息泄露、拒绝服务和提升权限六方面分类这些威胁。

#### 重点讲解

云风险很多并非全新攻击，而是因多租户、动态API、责任拆分和控制可见性下降而被放大。

#### 易错点提示

上云后CSC仍对安全和隐私策略负责，不能把全部责任推给CSP。

#### 核验状态

已按22.2和22.3十二类威胁逐项核验。

### 22.5 OpenStack

#### 题目原文

什么是OpenStack？

#### 教材依据

22.5；图22.9。

#### 解题思路

说明开源云操作系统定位、多租户IaaS目标和关键模块。

#### 参考解答

OpenStack是OpenStack基金会的开源云操作系统项目，用于创建和管理大规模虚拟专用服务器，提供面向公有云和私有云的多租户IaaS。它由可独立组合的模块组成：Keystone提供身份认证、令牌、服务目录和访问策略；Nova管理虚拟机计算实例生命周期；Glance发现、注册和检索虚拟机镜像；Swift提供冗余、可扩展的分布式对象存储。

#### 重点讲解

用户启动VM时，先通过Keystone取得令牌和服务目录，再由Nova、Glance、Swift等模块协作完成资源创建。

#### 易错点提示

Keystone不是虚拟机调度器；Nova负责计算实例，Glance负责镜像，Swift负责对象。

#### 核验状态

已按22.5和图22.9核验。
